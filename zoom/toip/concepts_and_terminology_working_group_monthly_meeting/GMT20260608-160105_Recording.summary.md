## Overview

The meeting focused on updates and progress with SpecUpT, a specification template tool for glossary management. Kor presented a comprehensive dictionary containing 11,000 terms from various specifications including NIST glossaries, which helps with translating and fixing auto-generated subtitles. Henk demonstrated two main use cases: creating new glossaries by borrowing existing definitions rather than writing them from scratch, and deduplicating existing glossaries to establish clear term ownership across the ecosystem. Drummond introduced a new SpecUpT template based on ITF structure that will be used for Trust Over IP specifications, and announced plans to train editors on using the tool. The group also discussed upcoming meetups in the Netherlands comparing EIDAS with SETI concepts, and potential collaboration opportunities including a possible one-day conference following SETI Summit and preceding IIW in November.

### Conference Subtitle Dictionary Tool

Kor presented a dictionary tool he developed for working on conference subtitles, which collects and updates specifications and glossaries including 11,000 terms from NIST. The tool allows users to search for terms across different glossaries and can filter results by specific categories. Kor demonstrated how the system can quickly look up abbreviations and provide relevant hits from various specifications.

### YouTube Subtitle Glossary Discussion

Kor discussed their work on fixing YouTube auto-generated subtitles, particularly for terms specific to Utah and abbreviations not commonly used. Henk explained that having access to a comprehensive glossary of definitions can help avoid duplicating work, as many existing glossaries contain definitions that could be reused. Carly suggested using a system to cluster definitions and suggest similar existing definitions rather than creating new ones.

### Glossary Integration and Use Cases

Kor explained that the glossary uses standard Spec of T format except for custom code that fetches NIST terms, noting there's a risk the NIST integration might stop working if their structure changes. Drummond expressed appreciation for the large combined glossary, which Kor attributed to AI assistance in fixing performance issues. Henk mentioned seeing two main use cases for the glossary, including using it as a foundation for generating new glossaries through a potential wizard tool.

### SPAC Glossary Use Cases Discussion

Henk and Drummond discussed two main use cases for creating glossaries with SPACs. The first use case involves allowing users to create their own glossary by picking terms and definitions from existing resources, while the second use case focuses on deduplicating existing glossaries to establish clear ownership of terms across an ecosystem. Henk demonstrated how the system can identify terms that have been updated or removed by their original owners, with an option to enable validation of external references to manage governance effectively.

### Glossary Visualization Tool Presentation

Kor presented a visualization tool that connects terms across three glossaries (Kerry Spec, ACDC Spec, and Caesar Spec) to show relationships between terms and definitions. The tool includes a game feature to help users learn by finding shortest paths between terms. When asked about tracking dictionary usage, the team confirmed they currently have no analytics or dashboards in place to monitor usage or traffic, though they mentioned GitHub might provide some analytics that they haven't explored yet.

### Glossary Specification Template Discussion

Drummond and Henk discussed a new specification template for glossary management based on spec up T, which includes directions for setup and a standard structure. Drummond mentioned that there were one or two minor tweaks needed but encountered some technical difficulties in locating the correct template during the meeting. The discussion highlighted the evolution of the template from an earlier version to accommodate more ITF structure requirements.

### New Specification Template Structure

Drummond demonstrated a new template structure for specifications that includes front matter, major sections, consideration options, conformance references, and terminology with glossary guidance. The team agreed to make this template the default option in SpecUpT's template picker, which Kor confirmed is already live. Henk informed Drummond that a previous text selection bug in SpecUpT has been resolved in the latest version, and Carly discussed plans to use AI to assist with generating HJSON or HTML content from specifications.

### Spec Up Tool Implementation Planning

The team discussed the implementation and training of editors on using the Spec Up tool, with Drummond noting that while version management of terms remains complex, modern AI assistance should help address user questions. Henk shared plans to organize one-day plenary sessions at venues adjacent to SETI and IIW conferences rather than separate full conferences, and mentioned challenges in European reception of US-based digital identity initiatives due to political tensions. The group also discussed upcoming conferences including GDC and a SETI interoperability event in Cambridge, England on July 13-14, with plans to coordinate presentations about alternative identity solutions.
