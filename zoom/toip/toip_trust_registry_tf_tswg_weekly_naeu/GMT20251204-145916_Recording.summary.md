## Details

### Trust Registries and Project Readiness

The meeting focused on the readiness of a project for public review, with Darrell explaining that changes discussed three weeks ago have been implemented and a blog post is prepared. Carly inquired about a digital identity pattern, which led to a discussion about trust registries and private communication methods. Scott announced the formation of a new task force at DIF for the Creator Assertions Working Group, inviting all Trust Registry members to participate. The group discussed the development of trust registries and their potential application in the COG and C2PA frameworks.

### Trust Registry Task Force Creation

The meeting focused on the creation and structure of a Trust Registry Task Force within COG, with Scott explaining its purpose and seeking input on naming. Darrell suggested calling it the "Registry Task Force" to avoid confusion, and Will expressed interest in joining. Scott emphasized the need for operationalization and pressure testing of the task force's work, potentially leading to modifications of the SPED. The group discussed the importance of using the task force to address trust registry issues, with Scott noting that the COG could benefit from it more quickly than other groups like First Person Project.

### PR02 Public Review Preparation

The team discussed pushing changes to PR02, which involves removing draft text and preparing for public review. Darrell emphasized that more engagement occurs during public review compared to earlier stages. The group also addressed administrative issues, with Darrell informing Cosmin and Will about the need to register on Confluence and explaining the open observer policy for Trust Over IP. Alex provided context on the implementation of TRQP, highlighting that the use of action and resource was insufficient for complex trust registry formats, particularly for AI agents, and suggested extending operations to include richer queries and metadata.

### Trust Query Protocol Expansion Discussion

The team discussed expanding the query structure to include assertion types and contexts, moving back towards the original proposal. Alex explained their solution involves using assertions with an assertion ID and type, coupled with an assertion-type context to enrich queries to the trust registry. Cosmin raised concerns about modeling complex information like birth certificates using the action and resource structure, which led to a discussion about the PAR model and its ability to handle complex queries. Drummond expressed interest in understanding the specific use case better, highlighting the potential impedance mismatch between the lightweight trustworthy query protocol and the more complex PAR model.

### Trust Registry Context Properties Discussion

The group discussed the structure of context properties in trust registries and how they relate to authorization queries. Cosmin raised questions about the distinction between policy and data in trust registries, particularly in relation to verifying issuers of VCs. Drummond explained that the trust registry protocol is designed for verifying issuers and authorizing actions, but does not store detailed information about the VCs themselves. Alex suggested that the current model might be limited in handling more complex queries about capabilities and roles. Darrell emphasized that the context object already allows for arbitrary, optional data to be included in queries, which could support more nuanced queries if the ecosystem being queried supports it.

### IRA Trust Registry Query Protocol Updates

Darrell explained how the context object in the IRA Trust Registry Query Protocol can be used to define metadata and handle complex queries, while keeping the protocol lightweight and performant. He suggested doing the technical work at IRA to inform the development of TRQP 2.1 or determine if the context object is sufficient. Drummond agreed that the context object mapping seemed to work well and noted that richer VC policies allow for more specific authorization. They discussed how the protocol can accommodate both simple and complex queries, with trusted query language available for more advanced needs.

### Apollo Specification Public Review

The group discussed moving forward with the public review of the Apollo specification, with Drummond and Darrell agreeing to proceed with Public Review Draft 02. Darrell committed to writing a blog post for the IRA website that includes a concrete example of how the query protocol can be used, while Drummond offered to help by adding a simple example to the blog post within 24 hours. Alex and Cosmin, along with Vladimir, plan to discuss the context and metadata requirements for AI agents and will follow up with Darrell as needed.
