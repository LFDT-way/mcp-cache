## Overview

The team discussed the development of a new meeting page system that automatically manages meeting documentation and integrates with various platforms like Confluence and Discord. They explored different documentation tools and collaboration systems, comparing the capabilities of Confluence, GitHub, and AI bots for managing information and coordinating across teams. The conversation ended with plans for future development of TSP-based MCP servers and discussions about AI tools for information management, along with holiday wishes for the new year.

## Details

### Meeting Minutes Automation Discussion

The team discussed the creation of a new meeting page by Wenjing, which automatically adjusts dates and calculates meeting minutes. Neil expressed concerns about the difficulty of finding meeting minutes and agendas, noting that content is often scattered across various platforms without clear organization. The group acknowledged this as their last meeting for the year, with Neil mentioning he would post something in general after the meeting.

### File Organization System Challenges

Neil and Wenjing discussed the challenges with the current file organization system, noting that multiple Google folders make it difficult to locate documents. They considered moving from Google Drive to GitHub, acknowledging that while GitHub might be easier for bots, it may not scale well for large amounts of documentation. Makki suggested that GitHub could be useful for creating templates and deploying agents, but acknowledged that not all users might be familiar with or prefer using GitHub.

### Bot's Confluence Integration Capabilities

The group discussed a bot's ability to write programs for tasks, with Wenjing explaining that bots are skilled at identifying limitations and creating workarounds, demonstrating intelligence and "scrappiness." They examined how the bot interacted with Confluence, noting that while it could search URLs and scrape data, it produced MD files that could be copied and pasted into Confluence rather than directly creating Confluence pages.

### AI Bot Confluence Access Demo

Wenjing demonstrated how an AI bot can write to Confluence by configuring an MCP connection and using browser credentials for authentication. The bot can perform tasks like listing Confluence spaces and finding specific pages without requiring explicit credentials from the user, as the browser's saved login information is used automatically. This raised security concerns, as not everyone can write to Confluence, and the process may be transparent to users who rely on browser auto-login.

### Confluence-MCP Integration Discussion

The team discussed the integration of Confluence with MCP (MCP server), where Wenjing explained that Confluence has official MCP support through a UI connection point, eliminating the need for running a local server. Drummond clarified that MCP servers act as API wrappers that handle mapping and interaction between agents and APIs, while Makki noted that Confluence subscription does not automatically include MCP subscription, requiring manual configuration.

### Confluence Meeting Automation System

Wenjing demonstrated a new system's ability to automatically manage meeting pages in Confluence, including copying, modifying dates, and adding agenda items. The system requires explicit consent from users before performing actions and can learn from user commands to automate repetitive tasks. The team discussed the system's functionality, with Drummond and Steven expressing amazement at its capabilities, and Steven inquired about the possibility of modifying code directly.

### AI Bot Integration Discussion

The team discussed integrating an AI bot with Confluence and other platforms like Discord and Zoom. Wenjing proposed using the bot to automatically update meeting documents with attendee information and relevant links from Discord. Steven suggested switching from Confluence to GitHub for better integration and functionality, as GitHub uses Markdown which would be easier for the bot to process. Drummond mentioned that they recently convinced LFDT to allow them to stay on Confluence. Neil raised concerns about GitHub's scalability for larger teams, sharing his experience working on a travel profile project as the sole developer.

### GitHub and AI for Team Coordination

The team discussed using GitHub and AI tools for managing multiple repositories and coordinating worldwide teams. Steven suggested using GitHub's multiple repository feature with AI assistance to sync different teams' work, while Wenjing demonstrated a tool that generates meeting agendas from Confluence data. The group explored the potential of GitHub Copilot for automating tasks and discussed its advantages over Confluence, noting that GitHub might be better equipped for such automation due to its heavier usage. Jeff raised a question about the specific use of GitHub for tasks like agenda generation, prompting further discussion on GitHub's various features and their potential applications.

### GitHub vs. Confluence Documentation Debate

The team discussed using GitHub repositories for documentation and collaboration, with Neil emphasizing that Confluence's structured approach provides better navigation and context for finding information compared to distributed GitHub repos. Makki explained that GitHub can be used similarly to Confluence by creating templates and organizing repos for different working groups, while Jeff expressed concerns about relying solely on GitHub for documentation rather than maintaining a diversified approach. The discussion concluded with Jeff sharing a story about a Wired article involving a deepfake of Sam Altman, though this appeared tangential to the main conversation about documentation tools.

### AI Bots for Knowledge Consolidation

The team discussed using AI bots to consolidate information across different working groups and improve knowledge sharing. They explored the possibility of using bots to automatically summarize meetings and provide relevant updates, with a focus on making information more accessible to those outside specific silos. The group also touched on the challenges of AI-generated content accuracy and the potential for bots to read and respond to each other's outputs, raising concerns about the volatility of truth in AI-generated information.

### 2026 Goals and TSPU Integration

The group discussed their upcoming meeting on January 8th, 2026, where they plan to focus on concrete deliverables and identify specific goals for the year. Wenjing suggested testing the integration of TSPUs and MCP into OAuth schemes, proposing to implement a TSP-based MCP server as a practical example. The team also briefly discussed AI tools like Perplexity.AI and M&I, which can cite sources and summarize news stories. The conversation ended with holiday wishes and plans to reconnect in the new year.
