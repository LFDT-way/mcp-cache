## Details

### Decentralized Trust Graph Working Group Meeting

The meeting began with Drummond welcoming attendees and acknowledging Joe Rasmussen's participation despite the time difference. Drummond shared the agenda for the March 4th Decentralized Trust Graph Working Group Meeting, which included updates on task forces, a report on the recent HOH Summit on Human Agency, and a demonstration of the SML wallet by Brendan Miller Leon. Drummond also mentioned the postponement of two action items from the last meeting and introduced new task forces, including the Agent Names Task Force. The group discussed the need for new repos and the development of the TOIP spec template. Attendees were encouraged to share their feedback on the recent HOH Summit, which Drummond described as having a packed agenda with high-quality content.

### H2H Connect App Success Review

The team discussed the success of the H2H Connect app at the Linux Foundation Member Summit, where it facilitated over 650 person-person connections, 250 human-to-agent connections, and 30,000 messages through secure chats. The app, developed by Affinity, demonstrated the viability of their trust graph technology, which was well-received by Linux kernel maintainers and LFDT leadership. The team was invited to a workshop with Linux kernel maintainers and received positive confirmation of their approach to decentralized trust solutions, with plans to submit their code to Linux Foundation Decentralized Trust Labs and potentially implement a verifiable trust community by October 8th in Prague.

### LFDT Labs Project Updates

Drummond reported on three new projects contributed to LFDT Labs, including OpenVTC for generating DTG credentials and a verifiable trust infrastructure. Geoff explained that the DTG credentials project is at version 0.3 and is implemented in Rust code by Glenn, while OpenVTC and the verifiable trust infrastructure are rapidly evolving with frequent code commits. The team plans to demonstrate Brendan and Alberto's work, which is built on top of the 0.3 DTG credential spec, in the next 15 minutes.

### Decentralized Trust Graph Model Demo

Drummond presented a new version of the Decentralized Trust Graph (DTG) model, explaining how it builds on the Web of Trust model by using decentralized identifiers (DIDs), verifiable relationship credentials (VRCs), and verifiable trust communities (VTCs). He highlighted the need for an automated process to handle trust relationships, which can be achieved through Verifiable Trust Agents (VTAs). Brendan Alberto demonstrated a mobile app implementation of the DTG model, showcasing features such as wallet setup, VRC exchange, and hardware attestation. The group discussed the use of witnesses and blockchain data registries for verifying trust relationships. The presentation and demo were well-received, with plans for further development and open-sourcing of the code on April 15th.
