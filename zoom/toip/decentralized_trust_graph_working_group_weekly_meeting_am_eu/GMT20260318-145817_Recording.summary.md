The March 18th meeting of the Decentralized Trust Graph working group focused on two main topics: updates from the Risk Assessment Task Force and a deep dive into agent names and agent pages. ### Agent Naming System Discussion

The meeting focused on discussing agent names and agent pages as a naming layer built on top of decentralized identifiers (DIDs). Drummond explained the background and importance of this initiative, highlighting the need for a trust-based solution to address challenges with human-meaningful identifiers. Markus demonstrated a live demo of how agent names work, showing a two-phase resolution process where an agent name is first resolved to a DID, and then the DID is resolved to service endpoints. The discussion included details about the syntax (domain/at/agent-name), the use of verifiable credentials for binding confirmation, and the verification protocol to ensure trust and prevent fraud. The group also discussed the need for a specification covering syntax, resolution protocol, and verification mechanisms, with plans for further development through a newly established task force.
