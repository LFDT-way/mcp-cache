## Agenda

📣 New Reporting Tools Task Force
The EGWG has approved a new Task Force to help streamline reporting from ToIP Working Groups and Task Forces to the Technical Advisory Committee (TAC), while also supporting preparation for our next ToIP AGM on October 28, 2026.
The objective is to develop optional templates, guidance, and AI-assisted tools (prompts, skills, workflows) that make it easier for WGs and TFs to provide structured updates that can be reused for both TAC reports and AGM materials.
Rather than relying on a few final authors who search and compile information, we'd like to create a process where WG and TF leads can contribute updates in a consistent format that can be efficiently collated into reports and presentations.

## Details

### Local vs Frontier Models Discussion

Carly and Sankarshan discussed the challenges of using local models versus frontier models for generating reports, noting that while local models can handle high-level reporting, they become ineffective when dealing with multiple input streams and complex data synthesis required for detailed presentations. Sankarshan mentioned that one hour might not be sufficient to cover all the work happening in the governance area, and Carly indicated she had updates and a proposal to share in the meeting.

### Frontier Models for Trust Prototyping

Carly and Sankarshan discussed the use of Frontier models and credits for Trust Over IP prototyping. Sankarshan expressed concern about using personal or free credits and suggested finding a more sustainable approach. Carly agreed and mentioned plans to meet with Ben and David Boswell at the Linux Foundation Decentralized Trust to explore building pipelines using internal resources and potentially RAG models.

### Local Model Proposal Discussion

Carly proposed creating a local model with a RAG built by the Linux Foundation that could query cross-project information and generate reports highlighting similarities and opportunities. Sankarshan acknowledged the proposal but emphasized the need to consider different information consumption levels when presenting details to various stakeholders, including both technical experts and broader Linux Foundation constituents.

### Linux Foundation Chatbot Customization

Sankarshan and Carly discussed customizing a chatbot for the Linux Foundation Decentralized Trust that would generate reporting and allow members to search and learn about different projects through a chat interface or report generation interface. Sankarshan mentioned that GitHub reporting is relatively straightforward and shared a link to a GitHub repository he had enhanced with AI to track weekly activities in DIF and TOIP. Carly was testing local models and discussed the differences between frontier models and context windows in their implementation.

### Data Extraction Pipeline Challenges

Carly discussed her challenges with a small local model that requires breaking down data into individual chunks for information extraction. Sankarshan explained that the monitoring page uses Python scripts rather than AI, and noted that working with Confluence would require creating an ingestion pipeline, which would be challenging as a solo effort. Sankarshan advised that the MVP would likely not be feasible without additional help.

### Collaboration Proposal Discussion Meeting

Carly discussed a proposal to join forces with other groups already working on a similar project, noting that David had mentioned others were involved and wanted her to create a proposal to share with these groups. Sankarshan suggested organizing an umbrella meeting to bring together all working groups to share progress and determine reusability. Carly confirmed that her next step would be to meet with David to discuss the proposal further, as she was not working on it independently.

### LLM Pipeline Project Shift Discussion

Carly and Sankarshan discussed a project shift from prompting to building an LLM pipeline with RAG, which requires significant infrastructure work and more resources than initially anticipated. Sankarshan emphasized that this type of project cannot be completed quickly with limited resources. Carly agreed to report back on next steps after consulting with David Boswell or Ben.
