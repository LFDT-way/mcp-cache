## Details

### Paladin Project V1 Progress Update

Matthew and Sankalp discussed updates on the Paladin project, focusing on the progress towards V1 release. Key developments included the merging of the V1 develop branch into main, enabling the creation of release candidates. They highlighted new features such as chain transaction ordering and the implementation of a grapher and dependency tracker package. Matthew also provided an update on the Java SDK Mentoring Project, which is set to begin in June with a selected candidate. The team reviewed the planning board, identifying ongoing work on functions and bugs, with a focus on coordinator selection and epoch signing based on block numbers. Matthew mentioned plans to review and update the project documentation, including diagrams and state machine descriptions.

### Tokenized Asset Banking Architecture Discussion

Sankalp discussed architectural considerations for banking integrations involving tokenized assets and deposits, seeking guidance on whether to use Zeto or Pente for different privacy domains. Matthew recommended Noto and Zeto as suitable token implementations for tokenized assets like CBDCs or bonds, explaining that Zeto might be better for cash-related use cases while Noto provides notarized issuer-backed functionality for specific industry needs. The discussion focused on understanding the performance characteristics and workflow implications of different privacy domains for Sankalp's architectural planning.

### Paladin ZK Scalability Discussion

Sankalp discussed potential transaction volumes of a few hundred thousand per day and inquired about the horizontal scalability of ZK proving capabilities in Paladin. Matthew explained that while Paladin currently generates proofs internally with limited horizontal scalability, the system uses pluggable ZK-compliant private key material and performance improvements are being considered for future versions. The group agreed to revisit these topics in the next community call and discussed plans for V1 development.
