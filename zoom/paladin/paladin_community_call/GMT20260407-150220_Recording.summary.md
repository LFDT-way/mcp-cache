## Details

### Paladin V1 Beta Progress Update

Matthew provided an update on Paladin's progress toward a V1 beta release, highlighting work on a new sequencing engine and coordination engine. He explained that the team has been focusing on hardening the system for large numbers of contracts and transactions, particularly complex flows involving multiple domains. Matthew noted that many bugs have been identified and fixed during this process, including memory leaks and stability issues. The team plans to cut a V1 beta in the coming days by resetting the main branch to the V1 developer branch, making the new sequencing engine the default for future releases.

### Paladin Implementation for Banking Research

Muhammad, a third-year computer science student from Indonesia, reached out to discuss his research on implementing Paladin for a traditional finance bank in Indonesia. He mentioned they had some issues with AWS hosting but planned to reach out on Discord for assistance. Sankalp introduced himself as working in blockchain and expressed interest in using Paladin for enterprise-grade privacy solutions with banks, sharing their successful deployment and seeking information about Paladin's future development and production readiness.

### V1 Beta Development Progress Update

Matthew discussed the development progress of the V1 beta, aiming for release by the next monthly community call. He mentioned that feedback from users like the current speaker would be valuable for the beta testing phase. Matthew also shared that Kaleido uses Paladin in commercial engagements and provides insights back into the open source project development.

### Linux Foundation Java SDK Mentorship

Matthew announced that the Linux Foundation had accepted their proposal for a Java SDK mentorship program, which will run from end of May through end of year. The program aims to expand Paladin's SDK offerings beyond the existing Golang and TypeScript versions. Muhammad inquired about when the program would be listed on the Linux Foundation website, and Matthew confirmed it was already listed, with applications open until the end of May.
