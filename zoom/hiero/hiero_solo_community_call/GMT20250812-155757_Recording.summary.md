## Details

### Solo Node.js Compatibility Discussion

The Harrow community meeting discussed Node.js version compatibility for Solo. Nathan confirmed that Solo supports Node 22 and 23, with Node 24 being untested but potentially compatible. Jeromy agreed to investigate running test harnesses against different Node versions to ensure compatibility. The team clarified that the minimum supported Node version in the documentation (20.18.3) is due to TypeScript compilation requirements, as Solo compiles to ECMAScript. Roger was advised to use the minimum version in his CI/CD workflows for consistency with documentation.

### New Release With Stability Improvements

Jeromy demonstrated a new release with several improvements, including bug fixes for solo node operations and the addition of a quick start destroy command. He explained that version 42 is more stable and includes enhanced output to help users transition from local node to solo. Jeromy also mentioned the addition of a flag to generate private keys during account creation, streamlining the process.

### Helm Updates and Bug Fixes

Jeromy discussed updates to the Helm dependency manager and bug fixes, including a fix for an admin key requirement in node addition. Jeromy discussed several updates on Solo, including progress on running it inside a Docker container, a GitHub issue being worked on by a contributor, and the redesign of the command structure for simplicity and better organization. Jeromy also provided an overview of Solo's components and functionality for Vignesh, who was new to the project, and Jason introduced himself as a user of Solo in their project.
