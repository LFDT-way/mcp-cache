## Overview

The meeting focused on discussing the Hiero Enterprise Java team's first release and addressing concerns about security measures and documentation. Jessica and Hendrik highlighted the need for clear documentation on Step Security pull requests, GPG key usage, and Maven Central authentication processes. They agreed to create separate issues for each topic and involve relevant team members, including Andrew and Roger, in providing information and guidance. The group also discussed the potential for automating the creation of "good first issues" and explored ideas for improving communication within Discord channels. Additionally, they touched on the rescheduling of Hendrik's workshop, which was postponed until May 11th to accommodate his travel schedule.

## Details

### Step Security and Snyk Guidelines

Jessica discussed the need to clarify definitions and guidelines about Step Security and Snyk in the governance repository, as some team members are unfamiliar with these tools or their management. She mentioned reaching out to Andrew and Roger for more information but had not received a response yet. Angelina provided an update on efforts to automate the process of creating good first issues, including the potential use of bots to address nitpicky changes and continuously generate new issues. The team plans to meet again next week to discuss findings and explore tools like CodeRabbit or Copilot for automation.

### Security Automation Planning Meeting

The team discussed plans for automation and documentation of security processes for Hiero Enterprise Java's first release. Angelina mentioned that more discussion on automation would take place in next week's Good First Issue meeting, where research findings will be shared. The group also planned to discuss the Hedera Discord's functionalities and roles, with Luis Vega potentially presenting about it.

### Hiero Discord Server Improvements

Luis Vega presented the improvements made to the Hiero Discord server, including the reorganization of channels and the implementation of a new role system with Sophie's help. The server now has segmented channels for different purposes, such as developer announcements and support, and includes a bot for tracking tickets and identifying recurring issues. Luis Vega also explained the new "Hiero contributor" role, which is given to people who actively contribute to Hiero, and demonstrated how it can be used to target specific announcements to relevant members.

### New Discord Server Discussion

The team discussed the creation of a new Discord server to facilitate developer communication across different organizations, including Hashgraph and the Linux Foundation. Jessica raised concerns about maintaining traction in existing Hiero Discord channels, while Luis Vega explained that the new server would complement existing channels by reducing friction for developers seeking support across different organizations. Sophie clarified that the new server would be useful for Hedira-specific questions about applications of Hiero tools, distinguishing these from general Hiero engineering questions better suited for the main Hiero Discord.

### Discord Integration Planning Discussion

The team discussed plans for integrating communication into both Discords, particularly focusing on how to connect Hiero users with the Discord community. Luis Vega explained the dual opportunity this presents for developers - both contributing to Hiero's open source and using it to build applications. The group agreed to start drafting guidelines for Discord communication in the governance repository to gather broader community input and align on the approach.

### Maven Central Publishing Requirements

Hendrik and Jessica discussed the requirements for publishing releases to Maven Central, identifying three key areas that need documentation and resolution: step security pull requests, GPG key usage, and Maven Central authentication. They agreed to create a GitHub issue to track these requirements and planned to schedule a follow-up meeting for Tuesday after the TSC meeting to discuss progress with Roger and Andrew. Additionally, they confirmed a workshop scheduled for May 11th at 9 AM, which will be conducted remotely.
