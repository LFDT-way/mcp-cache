## Details

### HIRO Website Redesign Meeting

Angelina led a meeting to discuss the HIRO website redesign, which will be version 2 and is based on a community voting process where Darshit's design was selected. The new design aims to make the website more dynamic than the current static version, with features like the Issue Explorer that displays issues across different Hiero organization repositories. The team is currently pushing PRs to the main branch for review and feedback, with plans to eventually move approved changes to the website redesign branch, and Angelina invited interested participants to help with additional open issues while requiring them to complete at least one good first issue first.

### Web Redesign Branch Merge Update

Daniel explained that he merged a larger PR from the web redesign branch to the main branch to avoid conflicts and keep the web redesign branch updated. He offered to give a demo of his work, particularly for the homecoming feature. Angelina suggested linking the issues being resolved to ensure proper closure when merging, and offered to enable screen sharing for the demo.

### Python SDK Progress Updates

Angelina provided updates on the Python SDK, highlighting progress on the TCK module and missing RPC relay methods. She encouraged contributors to claim beginner issues and emphasized the importance of leaving reviews, even when unsure, by framing questions. Angelina also mentioned that timeout issues in workflows have been resolved but asked the team to report any future problems. She noted that HIP implementations are ongoing, with HIP 1195 currently under redesign, and the team is waiting for the final design document before proceeding with related issues.

### HIP Updates and Automation Progress

Angelina provided updates on HIPs under review, noting that most SDKs have implemented HIP 1195, though Python implementation is still pending. She mentioned that HIPs 1068 and 1500 are still being reviewed by the TSC, with more information available in the upcoming TSC call. Angelina also discussed automation efforts led by Sophie, who is developing a consolidated automation application that will combine existing tools like the PR dashboard, linked issue enforcer, and broken link checker.

### Dashboard and PR Review Updates

Angelina explained that the dashboard updates in real time to check PRs against security standards and mentioned an upcoming demo of a new GitHub automation at the TSC call. She noted delays in C++ PR reviews due to a team member's new priorities but assured the team that work was continuing. Angelina encouraged team members to use the Discord channel for questions, particularly for longer discussions, and suggested posting directly in PRs for quicker answers.

### SDK Progress and Website Updates

Angelina discussed progress on various SDKs including JavaScript, Swift, Rust, Go, and Java, noting that Mustafa has been working on the Java SDK. She announced plans to release website version 2 by the end of the week or beginning of next week to allow community feedback before deploying version 3.
