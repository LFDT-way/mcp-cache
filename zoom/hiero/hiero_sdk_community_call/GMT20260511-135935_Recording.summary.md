## Details

### Python SDK Updates Status Meeting

The team discussed the status of the Python SDK updates. Angelina reported that they merged 1261 and are currently reviewing 1137, with plans to implement 1313. She mentioned some automation bugs related to timing but indicated these were being addressed. The team waited briefly for Rob to join before proceeding with the meeting.

### CI Pipeline Issues Investigation

Angelina reported ongoing CI pipeline issues with Solo that are being investigated by Manish, who is looking into cluster setup problems and potential runner-related issues. Keith suggested raising a ticket in the Solo repo if the issues are determined to be with Solo itself. Angelina confirmed that most blockers have been resolved, including issue 1137, and new features related to fuzzing have been added.

### HIP Release Progress Update

The team discussed progress on HIP releases, with current focus on HIP 1261, HIP 1313, and HIP 1135 in Release 73. Dian reported that work on HIP 1137 was completed across multiple SDKs, with JavaScript, Python, Java, and Swift releases already completed, and Rust expected to be released soon. The team identified Pectra support as a key future priority, though there was uncertainty about whether a design document needs updating for this work.

### PECTRA HIP Updates Discussion

The team discussed updates on HIPs related to PECTRA, including HIP 1340 and HIP 1414. Keith explained that HIP 1340 requires some SDK work, while HIP 1414 adds picture support for crypto transfer. The team debated whether to have one design document for all PECTRA work or separate ones for each HIP. Ivaylo initially volunteered to be the champion for HIP 1340 but later withdrew due to time constraints. The team agreed to discuss the design document ownership further in their daily meeting and continue collaboration through GitHub comments on the existing design doc in the SDK collaboration repo.

### Block Nodes Release Planning Discussion

The team discussed upcoming work related to block nodes and Release 75/76. Keith mentioned that block nodes are coming and will impact the community, requiring updates to CI pipelines. Robert confirmed there is a design doc for block nodes, but Nana suggested waiting on implementation until more information about community adoption is available. The team also noted that block streams will become default in consensus nodes around Release 75/76, requiring updates to test pipelines. Robert mentioned he would coordinate with Mario on running TCK tests in the block node environment.

### PR Discussion on Fee Estimation

Dian presented a PR addressing fee estimation issues, proposing a hard-coded check for no fees and automatic cost setting through a function. Ivaylo explained that the change would involve calling the mirror node contract to estimate gas requirements, but Robert suggested postponing detailed discussion until the team could review the PR more thoroughly. The group agreed to continue the conversation about the PR in the GitHub discussion rather than during the meeting.
