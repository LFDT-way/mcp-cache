## Details

### SDK Development Progress Updates

The team discussed updates across multiple SDKs, with Venilin reporting progress on block node discovery for the JavaScript SDK and Ivo sharing findings about issues with high-volume entity creation and access list implementation in the SDK. The team identified that the access list should be an array of objects rather than strings, which may require breaking changes across SDKs. Several SDKs are blocked on implementing HIP-1137 pending the implementation of mirror node endpoints. The C++ SDK team reported significant progress with 15 PRs merged in the past week, including new issue templates and a limit of 5 good first issues per contributor. Python SDK has released a new version and is working on finalizing HIP-1261 implementation, while waiting for missing protobuf fields to be added.

### Transaction Builder and Mentorship Updates

Robert and Hendrik discussed ongoing work on the transaction builder and templated return types, with Robert planning to submit a PR this week. Hendrik shared that he had been accepted as a mentor for an AGF mentorship topic about SDK v3 and invited Robert to co-mentor. They also reviewed a pull request for a mirror node API implementation, which Robert agreed to review and merge after addressing the missing DCO signature. Joshua, a new contributor from Uganda, joined the meeting to express interest in contributing to Hiero and was directed to explore good first issues on GitHub and use the Discord channel for questions.
