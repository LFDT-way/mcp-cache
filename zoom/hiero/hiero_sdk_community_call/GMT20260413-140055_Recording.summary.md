### Collaboration Hub Issue Templates Discussion

Sophie and Robert discussed the need to create issue templates for the Collaboration Hub to better manage increased community contributions, particularly following the Linux Foundation mentorships. Robert reported significant contributor activity in C++, with 52 merged PRs and improvements in contributor skill levels moving from beginner to intermediate issues. They also discussed updates on HIP implementations, with Robert noting changes to HIP 1261 that require fixes to align with updated mirror node APIs.

### OpenSSF Score Improvement Initiatives

Sophie announced a new release and explained that they discontinued using the changelog due to merge conflicts. The team is working to improve their OpenSSF score, which currently stands at 7.4, by implementing additional protections and a new workflow. They also discussed challenges with managing multiple contributors and the need for automated review processes. Sophie mentioned ongoing work on implementing linting using "rough" and introduced a new Codes QL workflow to increase their SSF score, suggesting that Rob could adapt it for use with C++.

### CodeQL and Security Tools Discussion

Sophie explained that CodeQL works by creating queries on code and enabling custom safety checks, while Courtesy allows configuring custom rules based on standard packages. Hendrik noted that using CodeQL from GitHub affects OpenSSF scores negatively, but using tools like SonarCloud does not impact the score. Hendrik suggested discussing this issue with Jessica to address the lack of flexibility in the current system.

### Code Analysis Tools Discussion

The team discussed the potential use of CodeQL and Codasy for code analysis, with Robert suggesting they could be used to check for breaking changes in merges. Hendrik explained that CodeQL aims to be a language-independent query language for code analysis, though he noted it could take years for such a standard to be widely adopted. The discussion concluded with Robert mentioning updates to best practices documentation by a contributor, though the details were cut off in the transcript.

### Repository Best Practices Implementation

The team discussed implementing issue templates and best practices guidelines for their repository. Robert proposed a template baseline for best practice guideline markdowns, which Hendrik supported. Hendrik expressed concerns about the quality of existing C++ content, noting it might be automatically generated rather than tailored specifically for C++. The group agreed to focus on making the repository ready for good first issues, though Sophie noted that best practice guides inherently require advanced skills and might not be suitable for beginner contributors.

### Repository Development Workflow Discussion

The team discussed the development workflow for their repository, noting that while it receives significant interest from contributors with various programming backgrounds, they need to establish clearer implementation guidelines before fully adopting a template-based approach. Robert identified some inaccuracies in the upcoming Consensus node release 1261 that need fixing, particularly regarding protobuf changes and API updates. The team agreed to postpone the presentation on SDK collaboration structure to the next TSC meeting after Angelina received triage permissions to create epic issues, which Hendrik has now approved and merged.
