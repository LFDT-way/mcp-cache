## Overview

The Hiero SDK Community Call focused on updates across multiple SDKs, including Swift, C++, JavaScript, and Python. Ivan shared updates on Swift and C++ developments, highlighting deprecations, new contributors, and ongoing initiatives. Ivaylo demonstrated a new dApp template generator for the JavaScript SDK and discussed ongoing fixes for integer overflow and race conditions. The team discussed the need to streamline local development environments and improve Solo performance. Keith suggested making the community calls bi-weekly instead of weekly to maintain engagement. The conversation ended with a brief discussion about the Hiero website layout and a call for feedback on recent pull requests.

## Details

### SDK Updates and Swift Migration

The meeting began with Angelina noting that while Rob would not be present, the call would proceed as planned. She mentioned the possibility of additional participants joining due to the snowstorm. The meeting then started with a discussion about SDK updates, focusing on Swift. Angelina invited maintainers to share any updates regarding the .46 release and changes from Swift 5 to 6 support.

### Swift and C++ SDK Updates

Angelina and Ivan discussed updates on Swift and C++ SDKs. Angelina mentioned that Rob provided updates on Swift, including deprecating CI dependencies, updating to version 6, and merging PRs for Good First Issues Initiative templates and guidelines. Ivan shared that Rob reported 10 new contributors for C++, 7 new PRs closed, and plans to add more Good First Issues. Angelina highlighted the success of the Good First Issues initiative on the Hiero website, mentioning new PRs and plans for an automation package to assist maintainers. She also mentioned an upcoming meeting about implementing the Good First Issue Initiative in JavaScript, which is expected to take place on Friday.

### JS SDK Template Creation Tool

Ivaylo demonstrated a new feature for the JS SDK, showcasing a dApp template creation tool that generates a React app integrated with Wallet Connect. The tool, which is currently a local command not yet released, allows users to specify a network and Wallet Connect ID to create a template in about 30 seconds. Ivaylo mentioned that the overflow issue had been fixed and the PR merged.

### DApp SDK Documentation Discussion

Ivaylo demonstrated a new subpackage for generating DApps, which allows users to connect wallets and execute transactions using the SDK. He mentioned that he had generated documentation for this new subpackage, but would need feedback from Simi and Kate about whether to create it within the SDK. Keith raised concerns about the accessibility of self-generated documentation in the past, questioning where users would view the new docs. The team agreed to consider this user journey when adding the new documentation, with Ivaylo planning to share any updated information on the docs with the team.

### JS SDK and Solo Development

The team discussed issues with the JS SDK, particularly regarding race conditions and transaction management. Venilin reported fixes for these issues and is investigating further improvements. They also discussed streamlining the local development environment for contributors using Solo, with plans to collaborate with the Solo team to create a more efficient setup. Keith highlighted concerns about Solo's long startup time, which Venilin confirmed as a significant issue. The team agreed to gather and share more information about Solo's problems to help improve the product. Finally, Angelina provided an update on the Python SDK's progress and mentioned upcoming HIPs for implementation.

### HIP Project Updates and SDK Delays

The team discussed updates on several HIPs (High-Importance Projects) and SDK implementations. Ivaylo reported that changes for HIP 1340 have been implemented and pushed to a PR, pending tech team integration tests. For HIPs 1313, 1261, and 1300, Angelina noted that while the Python SDK team plans to implement HIP 1261 soon, some team members are absent due to events, causing potential delays. Keith mentioned that updates for these HIPs from the Swift SDK team would be difficult to provide without Robert present.

### Community Meeting Schedule and Updates

The team discussed changing the community meeting cadence from weekly to bi-weekly, with Angelina and others agreeing that bi-weekly would be more suitable to allow for more content and updates. The group also reviewed a new pull request for the Hiero website layout (PR #158), and Angelina invited feedback from attendees on the proposed changes.
