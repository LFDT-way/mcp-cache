## Details

### Hiero SDK HIP 1046 Updates

The Hiero SDK team met to discuss updates on HIP 1046, which Ivan reported was completed with testing in the environment and domain names updated for web proxies on preview and testnet. Robert noted that a meeting with the mirror node team was scheduled for after this one to address issues with transaction tool execution. The team also reviewed progress on the client implementation for tracking shards and realms, with Ivan mentioning that the document had been updated with the final version of the design.

### Network Configuration Simplification Update

Ivan explained that they have simplified the network configuration by removing chart and realm specifications for mainnet and testnet, as these networks already have them set to zero. Instead, they decided to consume the chart and realm from the network itself when specifying account IDs, and will verify that the specified shards and realms match before retrieving them. For JSON initialization, they chose to separate the shard and realm parameters to handle various use cases more efficiently, leaving it to users to fix any configuration issues. Robert suggested creating documentation for possible JSON input configurations, and Ivan confirmed that such documentation might be available for some languages but not all.

### Regression Test Failure Review

The team discussed regression tests and consensus node issues. Robert mentioned that TCK regression tests were running well, but Roger reported 46 failures in the latest run. Pavel explained that 11 tests were failing due to expected issues, but Roger requested the SDK team to look into the failures. The team agreed to rerun the tests due to previous runner problems, and Robert said he would check with Vilo about some hedera errors that were supposed to be fixed.

### SDK Office Hours and Progress

The team discussed two main topics: a consensus team issue that Roger wanted to see resolved quickly, and the implementation of office hours for SDK work. Sophie reported progress on planning office hours, which would involve structured sessions either via Zoom or Discord, targeting new Python SDK users. The team also reviewed Roger's extensive pull request #127 regarding type hinting, which Sophie was reviewing, and Georgi shared that progress had been made on the SO option implementation in the C++ SDK, allowing for its addition to other SDKs and migration from local node.

### Solo Action SDK Progress Update

Georgi reported progress on the solo action implementation, including fixing version 37.1 and resolving estimate gas functionality issues. He noted that while there's no stable release yet, the transition to C++ was seamless and will be easy for other SDKs. Georgi identified that the solo action currently lacks local node-like account generation capabilities, specifically needing more than one account for testing purposes, and Roger confirmed this limitation while sharing his manual account creation workaround. The team agreed that adding a configurable account generation feature to the solo action would improve its functionality, with Georgi planning to implement this quickly.
