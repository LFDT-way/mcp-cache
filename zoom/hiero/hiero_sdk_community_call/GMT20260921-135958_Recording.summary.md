## Details

### SDK Community Priorities Discussion

Keith led the SDK community call and highlighted two major priorities: the deprecation of account balance query across all SDKs and the need to work with Hendrik on designing mirror node query functionality. The team discussed the light attendance and decided to proceed with the meeting despite waiting for additional participants.

### SDK Migration Progress Update

Dian provided updates on the SDK migration from account balance queries to mirror node queries, explaining that a proposal for consistent HTTP query handling across all SDKs has been developed and reviewed by Hendrik. The proposal allows applications to supply their own HTTP transport, particularly important for Java and Android implementations. Dian confirmed that Hendrik's review comments have been addressed and minor changes implemented, with plans to finalize and merge the solution for implementation across Java, JavaScript, and Go SDKs by the end of the week.

### Python SDK PR Update

Daniel reported that a PR for account balance query duplication in the Python SDK has been updated to address requested changes and is ready for re-review. Keith acknowledged this update and mentioned he would work on following up with colleagues regarding the C SDK this week.

### TCK Implementation Update Meeting

Daniel provided an update on the TCK implementation across SDKs, explaining that they created a separate repository for the TCK runner to integrate it into CI workflows. He noted that while testing was successful for most SDKs, C++ builds took 30-40 minutes to complete. Keith then mentioned reviewing Deanne's proposal and asked Daniel to discuss it further after sharing his screen.

### DOSI Implementation and SDK Updates

The team discussed an implementation by DOSI, with Dian noting they had been moved to work on solo parts and offering to arrange a meeting with DOSI or facilitate questions through chat. Keith mentioned he would present a security proposal at the next TSC meeting and indicated that the SDK would be presenting items with potential impact on SDKs. When asked about updates from the recent HashConf conference, Keith reported that SDK-related topics were not discussed there.
