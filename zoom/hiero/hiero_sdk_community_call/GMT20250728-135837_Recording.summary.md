### Python SDK Office Hours Planning

The team discussed two main topics: dual publishing and Python SDK office hours. For dual publishing, Angelina inquired about mockups and tools like Figma and M3, though Robert clarified these were not related to dual publishing. Sophie reported on the Python SDK office hours survey results, which showed users want supportive meetings, particularly on weekdays evenings UTC, with 4 new starters the previous week and 2 more this week. Sophie is working with Jessica to set up the office hours, pending final timing decisions and email addresses for invitees, and suggested the possibility of future general Hiero community calls to teach technical concepts across all SDKs.

### SDK HIPs and Implementation Updates

Robert discussed several upcoming HIPS (High Priority Items) related to SDK functionality. HIP 1139 allows topics to become immutable, HIP 1195 adds Hiero hooks for customizing entity behavior, and HIP 991 updates the max custom fees field for scheduled transactions. Keith pointed out that HIP 1139 has been revised and contains new functionality for key rotation, including the ability for submit keys to rotate to dead or active keys without an admin key. The team agreed to hold off on HIP 1139's implementation until the revised version is finalized. Hendrik suggested moving the SDK prototype presentation to a later meeting to accommodate Sofia's interest in the docker setup, which was deemed more urgent for SDK users.

### Local Solana Network Prototype Demo

Hendrik demonstrated a prototype of a Hiero solar action setup that can be run locally using Docker, which creates a full Solana-based network for testing applications without requiring Kubernetes or internet access. The setup takes about 2-3 minutes to initialize and automatically creates an account with 100,000 H bars, though currently users need to copy the account information manually. Hendrik noted that while the commands currently work only on Unix-based systems, there are plans to make the information programmatically accessible from the Docker container and to explore Windows compatibility.

### Local Transaction Testing With Docker

Hendrik demonstrated a new feature for testing Hiero transactions locally using Docker containers. He showed how to create accounts, execute transactions, and test file operations in a solo network environment. The feature is still fresh, having worked since Friday, and Hendrik has only shared it with Richard so far. Robert expressed interest in looking into this further, noting that it could make solo testing easier for users.
