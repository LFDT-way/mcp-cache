## Details

### SDK Account Balance Deprecation Proposal

Keith discussed two new proposals in the SDK Collaboration Hub, focusing on the deprecation of the account balance query and its migration to mirror nodes. The deprecation is scheduled for September 1st, 2026, with plans to replace the query with a health status check for nodes supporting ping functionality. Keith mentioned updating the proposal with a new PR to reflect these changes and sought feedback or questions from the team.

### Account Balance Query Proposal Discussion

Keith discussed a proposal to deprecate the current account balance query and introduce a new "mirror node account balance query" to improve performance. He plans to create discussion boards for community feedback on these proposals. Angelina reported that issues with GitHub maintainers have been resolved after recent adjustments to code ownership, allowing the team to merge automation and Dependabot PRs without approval delays.

### Python SDK Code Ownership Updates

Keith discussed the status of code owners and maintainers for the Python SDK, confirming that while there are some challenges with contacting external teams, the Python components are not currently blocked. He explained that after the TSC meeting, he escalated the issue internally to improve responsiveness from code owners. Keith also addressed the complexity around employee relationships with LimeChain and committer/maintainer roles, noting that they have implemented a new process requiring new committers and maintainers to make meaningful contributions before being added to repositories, with recent additions to the JavaScript and GO SDK repositories.

### C++ SDK Security and Maintenance

Angelina raised concerns about the C++ SDK maintenance, noting that there are multiple unresolved PRs and review issues. Keith acknowledged the problem and explained that he had previously attempted to appoint LimeChain members as committers but faced conflicts due to their limited repository contributions. Keith also highlighted a significant security concern regarding SDKs, explaining that malicious actors could potentially gain committer access and approve transactions that drain funds, given the billions of dollars involved in the Hedera network. He proposed implementing additional security vetting for committers and maintainers, while acknowledging the challenge of balancing community involvement with security requirements.

### SDK Security Enhancement Discussion

The team discussed security concerns around SDK maintenance and open source principles. Angelina suggested focusing on maintainers who are well-known community members and using GPG signing and DCO processes for verification. Keith raised concerns about potential high-value hacks that could be conducted through the SDKs, comparing the risk to a recent $9 million hack on the Hedera network. Sophie proposed implementing signed releases requiring multiple approvers and at least two reviews for merge commits as additional security measures.

### SDK Development Progress Updates

The team provided updates on SDK development across different languages. Mustafa and Dosi reported no new updates on Java, GS, and Go SDK work, while they continue addressing issues in their backlog. Sophia shared progress on Python SDK security measures, including stricter branch protection rules and AI monitoring that alerts about major issues within two minutes. Keith raised a concern about the similarity in rights between committers and maintainers, suggesting a need for separation of rights to enhance security, though Sophia explained that their current two-approval requirement provides protection against unauthorized changes.

### Automated Testing and Release Processes

The team discussed the importance of automated testing in release processes, with Keith noting that extensive testing is conducted before cutting releases for repositories like Consensus Node and Premier Node. Sophie raised concerns about branch protection, particularly regarding beta branches in Consensus Node, and suggested having more discussion about what constitutes security-sensitive code. Angelina inquired about permission to perform a SDK cleanup, specifically asking the Java maintainers if it would be acceptable to close and refactor older work dating back over a year.

### SDK Development Progress Updates

The team discussed updates on various SDKs, with Mustafa reporting work on Java SDK issues and Ivaylo mentioning ongoing PR reviews and unit tests. Angelina shared that the Python SDK team is waiting for hips approval and has completed dependency updates and TCK module work. Keith announced plans to follow up on the C++ SDK progress and committer-maintainer separation discussions, particularly regarding how to implement different levels of access permissions for new committers.
