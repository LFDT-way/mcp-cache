## Details

### SDK Meeting: Issues and Presentations

The SDK team discussed two main initiatives: the introduction of demo presentations during weekly meetings and the establishment of a "good first issue" weekly meeting to improve SDK contribution processes. The team confirmed that the first good first issue meeting would be held the following day before the TSC meeting, with the goal of refining issue labels and descriptions across all SDKs. Robert mentioned that while they had previously discussed V3 keys in detail, they would save further V3 discussions for a future meeting to cover topics that were not addressed in the previous session.

### V3 Development and API Planning

The team discussed the development of V3, focusing on creating a proof of concept (POC) and defining APIs before considering deprecation timelines. Hendrik emphasized the importance of community involvement in shaping V3 and proposed a timeline for the POC's completion by the end of Q1, with a TSC review to follow. Robert highlighted the need for breaking changes to improve the SDKs and suggested aligning V3 releases across all SDKs, though this remains uncertain. The team agreed to continue refining the API guidelines and welcome feedback from the community.

### Hiero SDK Documentation Strategy Meeting

The team discussed documentation efforts for the Hiero SDK, with Sophie sharing progress on Python SDK documentation and Hendrik highlighting a new Discord channel for SDK discussions. They agreed that while Python-specific documentation should remain in the Python SDK repo, generic SDK information should be moved to the community hub, with Robert suggesting they could experiment with this transition in a future meeting. Angelina proposed directing developers to the Hashgraph certification course for basic concepts, while Hendrik emphasized the need to maintain separate documentation paths for SDK users versus contributors. The team decided to save remaining topics for the next meeting on Monday.
