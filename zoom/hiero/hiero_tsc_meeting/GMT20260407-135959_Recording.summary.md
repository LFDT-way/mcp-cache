### Pectra Upgrade HIP 1341 Presentation

Fernando presented HIP 1341, an umbrella HIP related to the Pectra upgrade that includes 12 EIPs, with only 3 being applicable to Hiero. The 3 selected EIPs are: EIP2537 for BLS precompiles, EIP67623 for improving call data cost calculation, and EIP7702 for code delegation and account abstraction. Fernando clarified that the discarded EIPs are not relevant due to differences in blob support, validator schemes, and protocol changes between Ethereum and Hiero, with no user-facing impacts resulting from their exclusion.

### EVM Implementation and Delegation Plans

Fernando explained plans to execute standard Ethereum client spec tests as part of the EVM implementation in Hiero, with the goal of creating a compatibility matrix showing which features are supported and which are not. He then detailed HIP 1340, which focuses on implementing EIP-7702 for code delegation, introducing a new Type 4 transaction with an authorization list that allows EOAs to be converted into smart accounts or smart wallets. When asked by Alex about the relationship between delegation and Hiero hooks, Fernando clarified that the current HIP only addresses EVM execution and does not collide with hooks, though there are ongoing internal discussions about potential integration with hooks in the future.

### Hiero Delegation and Website Updates

Fernando presented on delegation concepts in Hiero, explaining how delegation can be set via Type 4 transactions or account create/update operations, and discussed the security model similarities to Ethereum. The team reviewed a new design proposal for the Hiero website, with Hendrik noting they received a second draft and are working to incorporate feedback. The TSC agreed to review the HIP proposal further before next week's meeting where they plan to address any remaining questions and potentially vote on it.
