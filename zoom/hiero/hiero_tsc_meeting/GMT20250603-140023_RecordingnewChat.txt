00:49:53	Richard Bair:	I’ve been thinking  about rewriting the relay in Java. With the Go relay being proposed, I had a question of whether we should just pile onto Go and contribute to that, or keep contributing to the JS relay, or rewrite in Java. The reason I’m thinking about Java is because (a) it will also be much faster than JS, should be Go-like performance, and (b) if we build it on the same tech stack as the consensus node and block node, then we have the ability to create interesting hybrid nodes by taking modules from each and combining them together. This could be useful to have simple standalone single node network (minus the mirror node) for development, for example. I think that would be interesting in that it would provide yet another innovative differentiation that could be useful for HIero.
