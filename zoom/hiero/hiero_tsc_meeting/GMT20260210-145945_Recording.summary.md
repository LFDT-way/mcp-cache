### HIP Votes and Node Rewards

The team voted on HIP 1137 and HIP 1357, with all votes cast in favor. Alex raised a question about the calculation of rewards for block nodes versus consensus nodes, which Richard addressed by explaining that both types of nodes would receive rewards from the same pool, with consensus nodes that also run block nodes receiving an increased amount. Richard also provided an in-depth explanation of the security considerations and trust model for block nodes, noting that consensus nodes would need to select block nodes they trust, and that all Tier 1 block nodes would be operated by council members.
