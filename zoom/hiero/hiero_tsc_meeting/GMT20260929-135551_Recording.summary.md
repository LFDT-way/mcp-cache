## Details

### TSC Voting Rerun Announcement

Hendrik announced a rerun of the TSC voting for maintainer seats due to technical issues that prevented some maintainers from voting in the previous election. The new voting period runs from September 28th to October 12th, and maintainers should have received an email with details about the updated election process. Hendrik also highlighted the recent rebranding of the HIRO website, including new features like an issue explorer to help newcomers contribute to the project.

### Webinar Planning and TSC Voting

The team discussed upcoming webinars, including one by Edward on Clippa and another by Hendrik and Edward scheduled for the next day. They also addressed a TSC voting process for adding new repositories to Hyrule, which currently had four submissions but was still waiting for more votes. The conversation ended with voting on HIP 1522 regarding account stacking configuration, where all TSC members present voted in favor.

### HIPs and TCK Testing Updates

The team discussed upcoming HIPs, with Mark announcing two related to using Operator Provisioner for consensus nodes and releases that will go to internal review next week before being presented to the TSC the following week. Manish and Danielle presented their work on a GitHub action for running TCK test suits inside CI, which addresses the gap in testing JSON-RPC server implementations when code gets refactored or new methods are added. The presentation included a demonstration of how the GitHub action works with different SDKs and generates reports on test results.

### GitHub TCK Testing Automation Proposal

Daniel and Manish presented a new GitHub action that automates TCK testing for SDKs by setting up solo and JSON-RPC server locally, eliminating the need for manual local machine setup. Hendrik and Alex asked questions about how TCK testing is currently handled across different SDKs and how versioning is managed, with Manish explaining they use TCK tags and commit hashes for version control. Keith suggested bringing the proposal to the TCK community call for further discussion with the right stakeholders, including TCK maintainers, rather than having the discussion in this meeting.

### SDK Community and Verification Updates

The team discussed several topics including SDK community calls, repository management, and identity verification processes. Keith agreed to ensure the right people are included in the next SDK community call and will add a deprecation notice to the Homebrew tools repository linking to documentation about the transition to MPM. The group also discussed evaluating OpenVTC as a potential identity verification solution, with Diane suggesting that Hart present on OpenVTC before the team implements their own regime, particularly to assess how well it works for newcomers.
