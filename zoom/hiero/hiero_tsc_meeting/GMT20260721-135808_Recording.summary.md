## Overview

The Hiero Technical Steering Committee (TSC) meeting focused on two main topics: GitHub maintainer diversity issues and HIP 1342 presentation. Jessica raised concerns about bottlenecks in repository workflows due to limited GitHub maintainer team diversity, particularly affecting the website repository where many pull requests have been blocked since March. Sophie and Angelina highlighted how the current concentrative team structure creates gatekeeping issues that deter new contributors and slow development momentum. ### GitHub Maintainer Policy Concerns

Sophie raised concerns about the lack of policy regarding GitHub maintainer teams at HIRO, noting that over 10-20 teams are dominated by single organizations with cross-repository permissions. She highlighted that this concentration of power in few organizations could create issues similar to those seen in GitHub maintainers, potentially affecting the day-to-day running of HIRO and causing delays in pull request merging.

### GitHub Maintainer Process Improvements

The team discussed challenges with GitHub maintainer approval processes and communication barriers. Angelina proposed creating a second team with permissions similar to GitHub maintainers to expedite reviews and approvals. Lindsay suggested creating a dedicated Slack organization and channel for Hiero to improve communication. Jessica expressed concerns about creating separate teams, arguing it could undermine vendor neutrality in the open source community, and instead suggested diversifying the existing GitHub maintainers team with additional community members.

### Website Performance and Diversity Concerns

Sophie raised concerns about website slowness and lack of diversity in teams and repositories affecting contributor experience, noting she has shifted focus to Hiero hackers due to faster development and less gatekeeping. She advocated for implementing diversity policies beyond the TSC to improve day-to-day activities. Keith responded that meaningful contributions and trust-building are necessary before granting senior admin roles in other repositories like ConsensusNode or MirrorNode, and clarified that he doesn't see a block at the PR approval level for the Python SDK.

### Repository Contribution Blockers Discussion

Sophie discussed two main blockers in repository contributions: permission issues and repository maintainer diversity, noting that less open repositories often lack descriptive issues or onboarding plans. Keith agreed that some repositories lack proper pathways for new contributors to become engaged, but suggested this creates a chicken-and-egg problem rather than being primarily a diversity issue. Sophie also highlighted communication challenges, mentioning that the TSC currently lacks a dedicated section for discussing Hiero-related issues and new ideas.

### TSC Communication and Engagement Challenges

The TSC meeting focused on communication and engagement challenges within the project.
