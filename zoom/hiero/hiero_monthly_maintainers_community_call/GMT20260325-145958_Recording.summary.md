## Details

### Project Roadmap Discussion Meeting

Jessica led the March Maintainers Monthly meeting with a focus on project goals published in the TSC repository. She highlighted eight key goals for Hiero and discussed the need for more detailed roadmaps, as the current roadmap on the website was removed due to being outdated and too generic. Jessica asked maintainers if their projects had existing roadmaps that could be published and made accessible to the team. Sophie confirmed that the current roadmap was not present on the website but did not provide details about alternative roadmap documentation.

### SDK Development Communication Updates

Sophie proposed creating regular digest posts about SDK development progress, similar to Angelina's weekly activity reports, to keep the community informed about ongoing work across different SDKs. Jessica confirmed that the Hiero blog is actively being promoted and encouraged team members to contribute their project roadmaps and updates. Sophie also explained that the website has been migrated from Hugo to a Next.js, TypeScript, Tailwind CSS structure while maintaining similar blog post creation processes, and Jessica invited team members to reach out with questions or suggestions about the website or roadmaps.

### Hiero.org Blog Content Strategy

The team discussed using Angelina's pull request as an example for adding content to the Hiero.org blog. Sophie suggested creating issues for blog posts, though noted this might be less efficient if the writer lacks domain-specific knowledge. Jessica explained that the Hiero.org blog should serve as the main source for project announcements and technical content, with the Hedera blog and other platforms helping to promote these posts. No specific questions were raised about the blog or roadmap processes.

### Admin Site Roadmap Feature Proposal

Michael proposed creating an admin site feature for the Hiero website that would allow maintainers to submit roadmap information in a standardized form, which would automatically generate blog posts and PRs. Jessica agreed this was a great idea and committed to researching existing tools or developing a solution to streamline the roadmap process. The discussion also covered updates on mentorship programs, cross-project collaboration with Web3J, and the implementation of OpenSSF scorecards across repositories, with Jessica explaining how these scorecards are used to evaluate project health and maintain graduated status.

### Project Evaluation Scoring Criteria

Jessica discussed the scoring criteria for project evaluations, noting that while the official minimum score is 10, this is practically impossible to achieve. She suggested that a minimum score of 7 might be more reasonable, though this is not yet official. Jessica also announced an upcoming Rare Evo event in Las Vegas at the end of July, inviting the Hiero community to participate in workshops or presentations, with potential support for travel expenses. She mentioned that Hendrik had previously presented at this event and would be giving a similar presentation online in May.
