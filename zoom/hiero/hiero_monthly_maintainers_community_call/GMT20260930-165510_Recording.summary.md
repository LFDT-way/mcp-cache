### Hyva Hackers Analytics Repository Update

Daniel presented work on the analytics repository, which is part of the Hyva Hackers org (a GitHub organization belonging to the Linux Foundation). He explained that the analytics project tracks code and contributor metrics for the Hyro organization, and has been used as a source of truth for official reports including contribution and project diversity data referenced in LFDT reports.

### New Analytics Dashboard Demonstration

Daniel demonstrated a new analytics dashboard featuring interactive charts generated from live data, replacing the previous PNG-based system. The dashboard includes features for analyzing repository contributors, HIP implementations, security scores, code owners, and CI runners, with data collected through searches for HIP numbers, issues, and PRs connected to specific implementations. The team will present these analytics to the TSC on Tuesday next week.
