## Details

### Python SDK Security Version Issues

The team discussed an urgent problem with the Python SDK release, where they currently force users to use specific package versions due to a failed security test with version 3.14. Sophie explained that updating the project would break compatibility with other packages, and Manish has been working on a pull request to address this. The team needs to determine which selected versions are safe from security threats and ensure the project builds at each version before proceeding with a new release.

### Dependency Management and Documentation Updates

The team discussed dependency issues and documentation updates. Manish added greater than or equal to operator to address dependency problems, though he wasn't sure if it covered all user cases. Sophie suggested giving users flexibility with optional dependencies but emphasized the need for clear documentation. Angelina highlighted Windows-specific challenges with dependency installation and suggested creating separate setup guides for different operating systems. The team agreed to update the README with clear installation instructions and create a Windows setup guide. They also decided to update the PR check test workflow to include Python 3.14.

### Windows SDK Installation Challenges

The team discussed challenges with installing SDKs on Windows systems, particularly for C++ and JavaScript development. Angelina explained that she had to use multiple terminal environments and install Chocolatey to resolve UV installation issues on her Windows 10 machine, while Aditya noted similar difficulties with C++ SDKs on Windows 11. The team agreed to document these errors to improve the onboarding process for Windows users, and Angelina mentioned ongoing work with JavaScript maintainers to address Windows-specific issues. They also discussed recent improvements to the website setup for Windows users, which now includes separate installation guides for Tailwind CSS and other dependencies that weren't included in npm install.

### Python SDK Release Process Improvements

The team discussed the need to improve the Python SDK release process to better accommodate users. Sophie and Manish explored the possibility of creating workflows to test minimum and maximum builds, with Manish agreeing to create a workflow for testing minimum builds. Aditya raised a question about the necessity of including versions in the release process, which led to a discussion about the challenges faced by SDK users due to conflicting package requirements. The team emphasized the importance of making the release user-friendly while ensuring compatibility with various tools and libraries.

### Release Process and Changelog Challenges

The team discussed challenges with their release process, particularly regarding the large changelog for version 0.1.11. Sophie expressed concerns about the overwhelming number of changes and the difficulty in categorizing them for users. The group explored potential solutions, including releasing in smaller increments and using CodeRabbit to identify breaking changes. They also considered implementing more frequent releases to reduce the number of changes per release. The team agreed to focus on source code changes in future changelogs and to investigate prompts for CodeRabbit on new releases. Manish's PR for Windows support was highlighted as a key priority, with Angelina and Aditya potentially helping with testing on Windows.
