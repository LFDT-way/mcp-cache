## Details

### Version 2 Release Discussion

The team discussed the recent version 2 release, which Sophie helped prepare. Angelina shared that they had decided to change their changelog format to focus on source changes and make releases more periodic to avoid overly long changelogs. They mentioned some recent updates to the Python SDK, including changes to the PyTest version and protobuf schema. Angelina also noted that PR 1137 was blocked due to protobuf issues, and someone was currently investigating this problem.

### HIP Implementation and Runners Updates

The team discussed upcoming HIP implementations and recent updates to Python runners. Sophie and Angelina are working on creating documentation for self-hosted runners to provide more clarity and background information. The team also noted that meetings have been shortened from an hour to 30 minutes. Manish was asked about the progress of unblocking issue 1137, but no further information was provided in the transcript.

### Heap Implementation and Protobuf Issues

The team discussed issues with a heap implementation and protobuf representation, where Manish reported missing fields in the protobuf version 72 and suggested updating to version 73. Dosi confirmed that the fields are not yet implemented, making the HIP blocked. The team agreed to wait for updates to protobuf and the HIP mechanism before proceeding further.

### Pull Request Review Process Improvements

Sophie discussed the challenges faced by the team due to a high volume of pull requests containing complex code changes, which has led to a delay in reviewing and addressing issues. She noted that while courtesy checks and tests are in place, some bugs are still being surfaced, suggesting a need for improved review quality. Sophie proposed slowing down the process to ensure thorough reviews and creating more TCK tests, which Manish, who has been overstretched, would be involved in. The team plans to focus on self-checking pull requests and ensuring they meet expectations to streamline the process.

### SDK Review Process Improvements

Manish discussed the process of addressing missing features and bugs in the SDK by starting with individual TCK tests and creating issues for each finding. Dosi highlighted issues with the current pull request review process, particularly the annoyance of constant changes leading to conflicts and the need for force pushing, which causes him to lose track of previous feedback. Sophie acknowledged the problem and suggested removing the changelog, which was previously tried but retained due to its convenience for releases, to improve the review process.

### Changelog Process Improvement Discussion

The team discussed changes to their changelog process, with Dosi proposing a new folder structure where PR authors would create files following a template, which would then be automatically added to the changelog. Angelina expressed openness to removing the changelog due to past issues with rebasing, while Sophie suggested improving pull request titles as an alternative way to maintain accuracy in release notes. The team agreed to try a new approach with the changelog and Dosi committed to making a proposal by the next call, which will focus on TCK-related work and improving review quality.
