Nadine explained how Hedera's SDKs are built on protobufs, which serve as the single source of truth for new transaction types following Hedera Improvement Protocols (HIPs). She suggested checking other SDKs' issues for potential implementation opportunities and highlighted the value of cross-referencing existing implementations across different SDKs. Sophie discussed the process of creating blog posts for the Hedera website, emphasizing that these contributions can be part of Hacktoberfest and are a great way to document SDK updates and improvements. Both Nadine and Sophie encouraged contributions to the Python SDK, including better documentation, blog posts, and video tutorials, with maintainers labeling "good first issue" candidates to guide new contributors.

Nadine explained how users can monitor upcoming network changes, including new transaction types and features, by reviewing proposals in the GitHub repository. She emphasized that while daily monitoring isn't necessary, interested parties can comment on proposals to provide feedback or raise concerns.
