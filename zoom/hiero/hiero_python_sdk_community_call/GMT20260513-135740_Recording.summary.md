### New Pull Request Review Process

Sophie explained the new pull request review process which involves three phases: junior committer, committer, and maintainer. She outlined the specific roles at each stage, noting that junior committers should focus on high-level quality checks while committers handle deeper technical reviews, and maintainers address the most complex technical aspects. Sophie mentioned that while the process is still being refined, it has replaced the previous manual approach and allows reviewers to jump in at any stage without waiting for specific approvals.

### Python SDK Review Process Pilot

Sophie explained that they are piloting a new two-reviewer process specifically for the Python SDK due to its unique requirements, which is not expected to be extended to other SDKs like C++. She advised reviewers to use more questioning language when uncertain and clearly communicate their confidence level in their feedback.
