The group discussed proposals for managing documentation across different repositories. Mark expressed support for this approach but emphasized the importance of having uniformity across documentation sites for better discoverability and learning. ### Documentation Management Challenges Discussion

The team discussed challenges with documentation management across different repositories and websites, particularly regarding mirror nodes and block nodes. Keith raised concerns about documentation duplication between docs.hedera.com and docs.hyro.org, expressing a preference to link to Hyro docs where possible rather than duplicating content. Steven agreed that all Hyro docs should be centralized in one location, with a proposal to create templates requiring sections like overview, architecture, and configuration across all repositories, though this would not require TSC approval.

### Solo Docs Automation Challenges

The team discussed challenges with solo docs, particularly the automation requirements that made maintaining them on Hyrodocs difficult. Mark requested an official proposal to present to the TSC regarding a single pane of glass approach, which would allow each repository to manage its own docs while syncing back periodically. The group also addressed concerns about Solo Provisioner documentation, noting that while it spans node types, it should remain on the Solo branded docs site rather than being mirrored to Hyrodocs to avoid maintenance issues and dead links.
