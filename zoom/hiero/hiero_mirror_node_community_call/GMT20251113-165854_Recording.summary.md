### Hiero Output 2.0 Network Upgrades

Mark and Keith presented an overview of three major network output upgrades, collectively referred to as "Hiero Output 2.0." The upgrades include HIP 1200 (TSS), block streams, and block nodes, which aim to increase data delivery speed, reduce storage and processing costs, and enhance scalability while maintaining decentralization. HIP 1200 introduces a new cryptographic scheme using network-wide signatures that enable self-contained, independently verifiable blocks, while block streams optimize data formatting and the block node increases processing efficiency for data verification and distribution.

### Threshold Signatures and Blockstreams

Mark explained the concept of Threshold Signature Scheme (TSS), which combines aggregated and threshold signatures to enable network-wide verification of block signatures. He described how TSS reduces complexity for Mirror Node operators by replacing multiple file verification with a single block proof, resulting in lower costs and faster verification times. Mark also introduced BlockStreams, a new data format that consolidates multiple existing data streams into one optimized stream, reducing duplicate data and improving end-to-end latency.

### Block Streams and Node Processing

Mark presented an overview of block streams and block nodes, highlighting their benefits for improving data processing, verification, and storage in the network. He explained how block items are streamed in real-time, reconstructed into blocks using a Merkle tree structure, and verified before being made publicly available. The introduction of block nodes, which process and verify blocks, allows for better data filtering, state proof generation, and historical archive maintenance. Mark emphasized the importance of upgrading Mirror Node software to leverage block streams and block nodes, which will reduce latency, costs, and complexity for Mirror Node operators.
