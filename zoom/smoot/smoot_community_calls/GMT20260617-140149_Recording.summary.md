Weijia reviewed the documentation and found it well-documented, expressing that the team will review it further. ### Testing Setup and HSM Discussion

Marelize explained that the testing setup is for local machines only and not intended for production environments. She discussed their previous work with IBM's hyper protect cloud HSM and Azure Key Vault, noting that Azure's solution is not a true HSM as it doesn't support PKCS11. Marelize mentioned that a bespoke Azure solution was added to their Signer fork based on bank requirements, though she personally doesn't consider it ideal for a production-grade hardware signer.

### AWS Cloud HSM Expansion Discussion

Weijia and Marelize discussed expanding the application to support AWS Cloud HSM, with Marelize confirming that support already exists in their private repository despite not being documented in the public repo. Marelize explained the technical limitations of AWS Cloud HSM's single slot configuration and noted that while clusters are possible, they haven't been fully implemented due to automation challenges. The conversation also covered quantum-resistant signing options, with Weijia mentioning their team's interest in SP1 as an alternative to traditional circuit-based proofs, and Marelize expressing willingness to investigate this approach further.

### Project Visibility and Code Management

Weijia and Marelize discussed plans to increase visibility for their project, including exploring a quantum-related topic and potentially writing a paper with Javier.
