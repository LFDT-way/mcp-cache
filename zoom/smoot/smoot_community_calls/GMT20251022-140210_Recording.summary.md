Marelize and Weijia discussed compliance verification for cross-chain token purchases. ### Cross-Chain Compliance Synchronization System

Weijia and Marelize discussed a cross-chain compliance synchronization system where compliance status from one chain can be verified and used on another chain. They explored how to handle expiration times and the need for a service to automatically detect and propagate compliance changes between chains. The conversation concluded with Weijia noting that smart contract developers would need to explicitly allow their compliance status to be updated by the delayer system, and Marelize suggested adding functionality to handle status changes like revocation or rejection.

### Compliance Rule Change Notification System

Weijia and Marelize discussed the need for a system to handle compliance rule changes across different chains. Marelize suggested using events to notify changes in compliance rules, similar to how validator updates are synchronized. Weijia agreed that an event-based system would be beneficial, but noted that scanning all addresses for changes might not be practical. They discussed the possibility of updating addresses individually when changes occur, but emphasized the importance of having a system in place to detect and respond to policy changes.
