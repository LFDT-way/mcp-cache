## Details

### CoAP Integration for Fabric Devices

Bernardo presented on a proposal to enable resource-constrained devices to connect directly to Hyperledger Fabric using the Constrained Application Protocol (CoAP), addressing limitations with current gRPC communication. The solution involves creating a thin adapter layer on the peer that translates CoAP messages to gRPC, using the same protocol definitions and endpoints as existing Fabric communication. Bernardo highlighted that this approach would require minimal core impact and would be implemented through a new plugin for the gateway, automatically generating necessary code. The presentation concluded with a review of the current status of the RFC, including discussions with maintainers and plans for code implementation.

### IoT Direct Fabric Peer Integration

The team discussed Bernardo's proposal to enable IoT devices to connect directly to Fabric peers, bypassing the current middleware proxy. Angelo raised concerns about trust assumptions and security implications, questioning whether modifying Fabric was necessary. Bernardo explained that the proposal would reduce complexity and enable direct communication for IoT devices, while Artem noted that the gateway service already handles similar coordination for regular clients. The discussion highlighted the trade-offs between security, maintainability, and ease of use for IoT workloads in Fabric.

### Certificate Signing in IoT Devices

Arne inquired about the device's capability to handle certificate signing requests and discussed the process of loading keys and certificates. Bernardo explained that the IoT device can perform both the signing of transactions and the initial authentication, and he suggested sharing more details about their implementation. Arne expressed interest in learning more about the process and offered to share relevant code from a previous project. Bernardo agreed to provide additional information if needed.

### Fabric EVM Integration Demonstration

Arne demonstrated Fabric EVM, a compatibility layer that allows Ethereum-like networks to interact with Fabric. He showed how it enables the execution of Ethereum chain codes and the use of Ethereum tools like MetaMask wallets on a Fabric network. The system uses EVM endorsers and a gateway API to facilitate transactions, though it currently lacks gas metering and balance management. Ilie requested a written description of the project for the next 2-3 weeks, with plans to move it to the main project repository for further discussion.
