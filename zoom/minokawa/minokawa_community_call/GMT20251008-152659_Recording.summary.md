## Details

### Zoom Technical Issues Meeting

### Linux Foundation Charter Review

The team discussed the status of their Linux Foundation charter, which is currently under review by IOG Legal. Kevin explained the proposed governance structure, including a Technical Steering Committee (TSC) with five initial members, and outlined the process for becoming a maintainer or contributor. The team also discussed merging unshielded tokens (UT) into the main branch, with Joseph presenting two options for integrating UT and composable contracts changes. They decided to merge UT into main to align with the expected release timeline for Compact 027.

### Release Dependencies Misalignment Discussion

The team discussed a misalignment between Midnight.js and Compact C regarding release dependencies, with Midnight.js suggesting their support matrix will include unreleased Compact C versions while the team previously expected Midnight.js support before releases. Thomas noted that Node Toolkit will have an unshielded tokens release this Friday using Compact C, which led to a discussion about managing multiple environments and the need for a clearer release process story. Kevin emphasized the need for engineering team clarity on how to handle releases supporting multiple environments, particularly regarding the transition from TestNet 02 to the new environment, with Compact C 0.26 being the last version to support TestNet 02 and 0.27 being the first to support the new environment.

### Unshielded Tokens Merge Discussion

The team discussed merging unshielded tokens into the main branch, with Joseph explaining that option two involves putting UT and composable contracts into a feature branch for internal release to Midnight.js. Parisa and Joseph clarified that merging unshielded tokens would be a breaking change, as it would affect standard library functions and potentially cause issues with contract compilation and deployment. Andrzej suggested releasing version 0.27 with unshielded tokens, while maintaining the standard O2 testnet to avoid breaking changes for users in the short term.

### UT Branch Merge Strategy Discussion

The team discussed the approach for handling beta releases and updates for Compact, considering the implications of merging UT into main or maintaining it as a separate branch. They agreed to maintain UT as a separate branch for now, acknowledging the increased developer time required for merging but noting the risk of critical bugs if they merged it into main. The group also touched on the potential for bug fix releases and the need to determine criteria for merging UT into main, such as successful end-to-end testing. Parisa mentioned the upcoming move under Linux Foundation and its implications for support.

### Unshielded Tokens Release Strategy

The team decided not to merge unshielded tokens into the main branch at this time and instead will cut a release from the unshielded tokens feature branch. They acknowledged this situation is not ideal and want to develop a better approach for future releases. Leszek raised concerns about the complexity of managing multiple parallel development tracks for unshielded tokens, composable contracts, and main branch changes. Kevin agreed this would likely create a messy situation that needs careful coordination.

### Confusion Over Version Release

The team discussed confusion around the release of version 0.25.103 with Ledger support, which was intended for internal testing but has been made public. Leszek explained that this version works with the Node Toolkit but lacks recent features. Kent and Thomas expressed frustration about the lack of proper release notes and communication, emphasizing the need for clarity in future releases. Thomas acknowledged the business imperative to deliver the network release by Friday, while Kent suggested that 0.26.0 could be used instead since it includes all the necessary features.

### Compact C Release Strategy Discussion

The team discussed the upcoming release of Compact C, focusing on the decision to merge UT into main. They agreed not to merge UT into main due to concerns about compatibility with the ledger and the need to address different user requirements. Thomas suggested not rocking the boat at this point, as the compiler features were not the main focus of the release. The team also discussed the transition from Midnight.js to Note Toolkit, with Andrzej explaining the differences between the two tools and their integration with Compact.

### Compiler Release Strategy Discussion

The team discussed the release strategy for a compiler and toolkit, with Thomas noting that while the current internal release might not be ideal, they haven't received external requests for it yet. Kevin raised concerns about not proactively addressing features until external pressure arises, while Joseph and Parisa emphasized the importance of clear communication about the intended use of releases and the need for better cross-team collaboration. The team agreed to keep the UT branch longer and for Kevin to review upcoming milestones to determine when a full stable release might be needed.
