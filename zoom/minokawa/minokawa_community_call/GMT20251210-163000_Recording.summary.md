## Details

### Compact 0.27 Release Planning Update

Kevin discussed the Compact 0.27 release, which was the first since moving repositories. He mentioned debugging issues with release actions and creating an RC1 build. The release is being held until the MS2 release, which will announce and enable preview and pre-prod environments. Kevin proposed publishing release binaries in a subdirectory of the release repository to accommodate partners, including the Lace wallet, who want to test the compiler.

### Binary Removal and Version Management

Kevin explained that while the binaries are committed to the repository, they will be removed in the future due to their large size. He also proposed a plan for handling multiple ledger versions in the short term, involving the creation of release branches for different environments (pre-production and preview) and using alpha and beta designations for releases. Kevin suggested that bug fixes need to be cherry-picked to all affected release branches, and proposed updates to the dev tools to handle versions appropriately.

### TestNet O2 Discontinuation Discussion

The team discussed the discontinuation of TestNet O2 support, with Kevin confirming it will be turned off in the coming weeks. They addressed version naming issues, particularly regarding alpha versions and package manager conflicts, with Kevin noting that their development tools may need updates to handle version comparisons correctly. Casey was introduced as a new team member who will work on updating DevTools in the short term. The team also explored the possibility of creating a single compiler release that supports multiple ledger versions, though Kevin acknowledged uncertainty about handling different standard libraries and runtime versions.

### Compact Export Repository Transfer Plans

Kevin discussed issues with the compact export repository, including settings that required re-approval for minor changes and the need to resolve all comments. He also addressed plans to transfer the repository to the Linux Foundation, noting that legal discussions are ongoing. Kevin proposed maintaining a fork or mirror of the LFDT repository due to concerns about GitHub actions breaking after the transfer. He suggested two potential workflows: continuing to make PRs in a private fork and pushing changes to the public repository, or importing code to the fork to maintain CI and release capabilities.

### Compact Repository Transfer Discussion

The team discussed the timing of transferring the Compact repository, with Bob requesting immediate transfer despite Mark's suggestion to wait until the 19th. Kevin explained that Bob was concerned about further delays, as the Compact repository is the only midnight repository that remains closed source and was identified as a priority for opening. Kent proposed setting up a job to monitor the repository and create a full copy, but Kevin and others agreed this might be too complex and could cause synchronization issues. The team acknowledged that once the repository is transferred, they will have a public repository that can be used for projects, issue tracking, and bug reports, and Kevin committed to working with SRE to create clear documentation for the transfer process.

### JavaScript, TypeScript, and Compact Updates

The team discussed JavaScript and TypeScript keyword reservations, deciding to reserve all reserved words and strict mode reserved words while not reserving contextual keywords at this time. They addressed questions about documentation restructuring, with Kevin explaining that the docs team has been restructured and is now being handled by individual engineering teams and the Midnight Foundation DevRel. The team also discussed Compact language features, including the lack of block timestamp API in Compact and the need for better understanding of the new paradigm compared to EVM. They agreed to set up a meeting with the ledger team to address this. Finally, Seba emphasized the importance of sharing work and updates with the community, especially now that the token is live, and Kevin committed to sending release notes to help promote new features.
