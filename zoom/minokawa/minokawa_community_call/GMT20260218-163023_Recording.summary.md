## Details

### Compact 1.0 Release Planning Update

The team discussed upcoming plans for Compact 1.0 release, which will include new cryptographic features like Warm Curve support and hashing functions, though these will initially be experimental. Kevin announced that the project's quarterly report to the Linux Foundation Distributed Trust is due March 6th, and he will create a boilerplate structure for TSC members to complete. The team has reduced security vulnerabilities from over 200 to approximately 75, with plans to publish a scorecard to track progress.

### PRD Requirements for Feature Justification

Kevin clarified that while PRDs are useful for justifying new features, they are not always necessary, especially for community-proposed ideas. He emphasized that features should be well-motivated and solve legitimate problems.

### Search Order Path Discussion

The team discussed changes to the search order for module files, where Kent proposed making the relative path of the including file the first search location. The main question was whether the default path should be empty or include a dot, with Kevin expressing a preference for not including the current directory to maintain deterministic import behavior. The team agreed to leave the default path empty if the Compact Path environment variable is not set, and Kent noted that if CompactUp sets the Compact Path, it should follow whatever decision is made for the default case.

### Compiler and Toolset Environment Setup

The team discussed compiler usage with shell scripts and JavaScript tooling, focusing on making the process more foolproof. Parisa and Kent clarified the environment variables for the Compact Developer Toolset, confirming that the correct variable is "compact_path" rather than "compact_home." Kent agreed to set the path empty by default and proceed from there.

### JavaScript Compiler Testing Discussion

The team discussed executing the compact compiler with JavaScript, noting that their default tools have been working well without issues. Kent mentioned that if the change breaks, it would be an interesting question to investigate, though he couldn't provide a quick way to test it due to the default setting of looking in the current directory. Kevin apologized for not having an agenda document ready for the next meeting and promised to work on it.
