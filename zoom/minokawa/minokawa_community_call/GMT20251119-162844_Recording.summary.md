The team discussed several updates, including the need to test CI actions that copy documentation and identified a gap in the language reference documentation, which is 8 months out of date. They plan to change the curve point type in the standard library to "native point" and introduce a new "JubJubPoint" type, with the former likely becoming a type alias for the latter. The team is preparing to transfer the compact export to the Linux Foundation, pending legal approval of a project charter, and expects GitHub actions to break during the transition, so they will maintain a fork of the repository to ensure continuity.
