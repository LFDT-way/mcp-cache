## Details

### Org Migration Progress Update

The team discussed progress on the org move, which has been successfully completed with all organizations migrated. Dan is working on final updates to the CLI and Firefly core, with plans to release a candidate version after reviewing pending PRs. Enrique mentioned closing down old PRs, particularly those containing AI-generated changes and minor comment fixes, while also addressing Dependabot and Snyk updates.

### SNCC Account Disabling Process

Enrique and Ry discussed disabling and closing SNCC accounts that lacked DCO, with Ry confirming the disabling process. Enrique outlined a five-step process for releasing updates, including updating manifests in the main repo with new images for components. Simon interrupted to mention the release of version 071, noting it contained only minor changes including a bumped vulnerable package. The discussion ended with Simon explaining issues he encountered with API v1 endpoints when running tests locally with the Firefly Cardano repo.

### Firefly Core Container Updates

Enrique and Simon discussed updating the Firefly core container and CLI for testing. They agreed to release a CLI RC first, followed by updating Firefly and creating a 1.5.0 release candidate. Enrique mentioned potential fixes, including publishing a manifest.json to address GitHub API limitations. They also discussed the NPM publishing process and considered renaming the package to align with the GitHub organization, though no final decision was made on this change.

### Package Naming Convention Discussion

Ry and Enrique discussed package naming conventions, with Ry recommending continuing to use the old NPM namespace since they can publish through a trusted publisher. Enrique suggested potentially using a new organization name in the future if they have multiple Node.js packages to maintain consistency. The discussion concluded with Ry mentioning he would handle Dependabot PRs and needed to complete package migrations, specifically for token versions.

### Storage Cleanup and Release Planning

Ry discussed a script written by Claude to clean up storage by removing unused images that are not dependencies or tagged, noting this is a future problem rather than an immediate concern. Enrique mentioned plans to call an RC soon for end-to-end testing and V150 release, and noted the need to update the brew PR for CLI publication and check documentation links. The team experienced some challenges with the Firefly move but made progress overall.

### Documentation Updates and Image Fixes

Enrique and Ry discussed updating a README file and fixing broken images in the documentation. Enrique raised a PR to delete outdated code hierarchy content and identified several broken images that need path updates. They determined that the images are currently in a different repository (.images) and need to be moved to the GitHub repository to fix the redirects.

### Dependabot Insights Vulnerability Management

Ry demonstrated how to use Dependabot Insights to group vulnerability fixes, showing Enrique the process through the settings menu. Ry mentioned plans to create PRs to combine vulnerability fixes for Firefly, ETHConnect, and other dependencies, which would simplify the review process by consolidating multiple dependency updates into single PRs. Enrique expressed appreciation for learning about this feature, and Ry also discussed the typical process for releasing Helm charts after finalizing the CLI and core versions.

### Security and Quality Issues Discussion

The team discussed security and quality issues, including the OpenSSF score which had decreased. They identified several problems including unpatched vulnerabilities, missing dependency pinning, and errors in branch protection and release signing. Ry mentioned he had submitted PRs to address some of these issues, and the team noted that merging these changes would help improve the security score. The conversation ended with plans to monitor the issues and continue discussions on Discord.
