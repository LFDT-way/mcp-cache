### Firefly Annual Report Approval

Enrique announced that the Firefly annual report had been approved by the Technical Advisory Council, maintaining the project's graduated status. The report highlighted areas for improvement including reducing reliance on Kaleido, addressing OpenSSF security issues, and shortening PR and merge times. Enrique outlined next steps including releasing version 1.4, stabilizing the OpenSSF scorecard, adding an adopters MD file, and migrating the GitHub organization from Hyperledger to the Firefly-LDT organization.

### Hyperledger Firefly Integration Planning

The team discussed the integration timeline for TX3 and Palace 1.0, which are currently unstable and waiting for proper releases before being integrated into the connector. Enrique introduced a new organization called Hyperledger.Firefly and announced that Dan, an engineer at Kaleido, will help move existing repositories into this new organization. The team agreed to create a Discord thread to discuss the complexity of the repository move, with plans to track the work in the Firefly board and address issues around Golang updates, Cardano integration, CLI publications, and documentation updates. Enrique also suggested exploring GitHub discussions as an alternative to issues for better threading capabilities.

### Firefly Repository Governance Updates

Enrique discussed the governance structure and maintenance processes for Firefly repositories, including the use of LFX Insights to track contributor activity and project health. He proposed taking a checkpoint to assess active maintainers and potentially removing inactive ones through an official vote. Enrique also suggested updating repositories to include the latest CVEs and Go versions before transferring them, and potentially revising the process for handling CVEs and Snyk PRs to address DCO issues.

### Security and Quality Tools Discussion

Enrique and Simon discussed security and quality tools, including the availability of agents for LFTT repositories and the use of PandaBot versus Snyk. Simon agreed to address Dependabot issues on the Firefly Cardano repo before the next meeting and confirmed his availability on Discord to assist Dan with any Cardano-related questions during the upcoming organizational move.
