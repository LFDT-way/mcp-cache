## Details

### BASE-U Contributors Call September Update

Justin led the September BASE-U Contributors Call and discussed several key topics. He addressed the large number of outstanding PRs (approaching 70) and explained the process for reviewing them, noting that draft PRs are not reviewed unless specifically tagged. Justin also mentioned the upcoming 2027 roadmap development, highlighting Hagoda as a major component and encouraging contributors to suggest features for private networks and tech debt items that need attention.

### Permissioned Network Block Period Challenges

Matthew and Justin discussed the implementation and maturity of the permissioned private network feature, particularly focusing on empty block periods. Matthew explained that while short block periods are beneficial for high-throughput scenarios, combining them with longer empty block periods presents new challenges for validator voting and chain health observability in permissioned networks. He mentioned that he has submitted PRs for metrics to help monitor chain health during periods of intentional inactivity, which Jason is reviewing.

### Transaction Pool Development Planning

Matthew discussed current priorities including the Bonsai archive with proofs that Jason is working on, and the development of official plugins in a Besu-owned repository. He mentioned plans for transaction pool administration features that would give enterprise users more control over which transactions are accepted into the pool, though this is planned for 2027. Justin shared information about upcoming frame transaction concepts that will introduce more dynamic transaction pooling rules, emphasizing the need for stateless validity checks to prevent DOS attacks in the mempool environment. Fabio suggested that transaction pool implementation could potentially be made into a plugin to allow for different customization options based on enterprise needs.

### VPOS/VOPS Implementation for Mainnet

The team discussed implementing VPOS/VOPS for Mainnet as a plugin to avoid impacting Private Networks, with Fabio suggesting specific implementations for performance optimization and gasless networks. Matthew noted that while most users operate on free gas, some still use non-free gas for network capacity distribution, and highlighted an example of how a mainnet behavior change affecting gas limits impacted enterprise users. Justin announced plans to organize a meeting about Hagoda and invited the group to participate or provide rankings on Forecast.

### Private Network Testing Solutions

Fabio requested a way to test changes on private or permission networks similar to public testnets, as the team is currently blind to potential issues in these environments. Matthew explained that the existing BFT soak test, which runs through various forks including London and Shanghai, could be a useful tool for this purpose. He noted that the soak test recently started failing and is working to make it more reliable for public chain development, suggesting it could be a good starting point for Fabio's testing needs.

### BFT Test Implementation Discussion

The team discussed implementing a BFT test that currently fails unreliably and takes over an hour to run. Fabio suggested using GitHub actions to provide alerts on PRs after failures, similar to how Hive tests are monitored manually. The group agreed to first make the test run on a schedule and investigate notification options, with Matthew planning to address the test failures and propose workflow changes. They scheduled a follow-up meeting for Tuesday, September 8th at 1pm GMT to review a large list of tech debt issues, with Justin agreeing to post the meeting details in the Besu Contributors channel.
