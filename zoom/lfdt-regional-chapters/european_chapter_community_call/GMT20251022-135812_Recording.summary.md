### FHE for Public Blockchain Computation

Ghazi explained how Zama applies fully homomorphic encryption (FHE) to public blockchains, allowing encrypted data manipulation without decryption. He described their architecture, which uses a coprocessor to handle encrypted computations while the blockchain manages pointers and events. This approach extends public blockchains without requiring changes to validators, enabling secure computation of encrypted data.

### FATE: Encrypted Data Processing System

Ghazi explained how FATE operations are executed using encrypted data stored in FHE coprocessors, with pointers stored on public blockchains like Ethereum. He described the validation process, where operations are defined in smart contracts and encrypted data is processed asynchronously by the coprocessor, which can be scaled horizontally to handle more transactions. Ghazi also detailed how users submit encrypted inputs to the blockchain through a browser or client, including generating a ZK proof to validate the data's authenticity.

### Blockchain Zero-Knowledge Token Transfer

Ghazi explained the process of using encrypted data and zero-knowledge proofs in a blockchain system. He described how a user can transfer tokens by encrypting the amount and generating a proof that verifies the encryption without revealing the actual amount. The gateway stores the encrypted data and validates the proof before issuing a signature and handle, which the user can use to call a smart contract. The smart contract then verifies the handle and signature before processing the transaction.

### ERC-7984: Confidential Token Standard

Ghazi explained the development of a new ERC standard (ERC-7984) for confidential tokens, which replaces integer-based transactions with encrypted handles. The standard was created in collaboration with OpenZeppelin and aims to be technology-agnostic, allowing different encryption methods while maintaining compatibility across the ecosystem. The standard is currently in draft phase and is being discussed with ecosystem partners, with feedback already received from custody solutions regarding regulatory requirements for displaying transaction values. Multiple technology providers including Zama, Phoenix, and INCO are involved in the Confidential Token Association, working together to build a unified ecosystem rather than fragmenting it.

### MPC-Based Ethereum Data Encryption

Enrique and Ghazi discussed the encryption and decryption process for data stored on the Ethereum blockchain using an MPC-based approach. Ghazi explained that while data is encrypted with a public key, the decryption key is split into shards held by different nodes. These nodes collaborate to check access control lists stored on the blockchain before performing partial re-encryption and decryption, ensuring that only authorized users can access their data.

### Blockchain Data Standardization Initiative

Ghazi discussed the standardization of confidential data in blockchain smart contracts through ERC-7984, emphasizing the need for ecosystem adoption and compatibility to overcome fragmentation. Dominik and Tomaz expressed interest in spreading awareness about the initiative and connecting Ghazi with relevant ecosystem players, while Shane noted the importance of comparing solutions like Paladin and Zama. The conversation ended with plans for future collaboration and standardization efforts.
