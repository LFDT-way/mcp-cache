## Details

### LFDT TAC Meeting Updates

Hendrik moderated the LFDT TAC meeting in place of Arun. The discussion began addressing the annual review process, though the transcript ended before completion of this topic.

### Smooth Project Communication Strategy

The team discussed communication challenges with the Smooth project regarding their annual report. David explained that a Smooth maintainer had responded to some questions but wasn't regularly checking Discord, and the team agreed email would be the most effective communication channel going forward. The group decided to use the established GitHub issue to follow up with the project to complete their report responses, rather than pausing discussion until the mid-year report. Marcus was asked to reply to the GitHub issue again to request specific updates be added to the report before sending a final email to the maintainers for approval.

### TAC Meeting and Reporting Updates

The team discussed inviting Enrique to a future TAC meeting to address communication issues and gather more information on AI guidelines. Diane set a deadline of September 10th for receiving an update and meeting invite from Enrique, with the group agreeing to move forward with Arun's previous suggestions if no response is received. The team also acknowledged being behind on mid-year report reviews and discussed the overdue Minokawa annual report, which needs to be addressed by next Thursday.

### Lab Proposals and Communication Updates

Kevin apologized for missing a report deadline and delegated report writing to Parisa, who will provide a draft next week. The team discussed moving to Discord as their primary communication channel, which was agreed upon in their TSC meeting. Ry announced that three lab proposals have been submitted and requested lab stewards to review them, noting that the review process has changed from a GitHub PR-based system to a GitHub issue-based PR system. Diane mentioned that Carly from Trust Over IP has submitted a new proposal that needs to be added to the discussion.

### AI Reporting System Proposal Review

Carly presented a proposal for an AI-powered reporting system to streamline cross-project reporting across the Linux Foundation, specifically suggesting integration of meeting notes, documentation, and discussions from platforms like Zoom, Confluence, and GitHub. Diane acknowledged the proposal's validity but noted it needs refinement, particularly regarding GitHub metrics for code-based projects, and suggested focusing on Trust Over IP's October mid-year report as a pilot before expanding the system. The group agreed to review the proposal and discuss it further next week after collecting feedback from committee members.

### Knowledge Base Implementation Proposal

Carly presented a proposal for building a knowledge base using RAG architecture to improve document summarization and reporting, noting that while she has experience with basic AI tools at her university, she lacks expertise in implementing more complex solutions. Enrique suggested exploring open-source tools and LFDT standardization efforts, while Matthew inquired about Carly's previous successful implementations of similar approaches. The group agreed that while Carly's proposal provides a good starting framework, further discussion with technical experts would be needed to develop a more realistic implementation plan.

### Lab Proposal Process System Change

David offered to connect Carly with lab leads Bobby and Jean-Luc, and Diane agreed to join the discussion. The team reviewed a new lab proposal process that uses issues instead of pull requests, with Ry explaining that this change addresses mechanical issues and DCO challenges that were occurring with the previous PR-based system. The group discussed how approved lab proposals would still require manual repo creation, and Diane noted that a pre-existing Clipper proposal would need to be ported to the new issue-based system.

### Clipper Project Lab Proposal Discussion

The team discussed proposing a Clipper project as a lab proposal, with Hendrik explaining it involves a cross-ledger protocol for inter-network communication between Hyro-based and Biso-based networks. Hendrik requested moving the discussion to a future tech call to allow for more thorough review, as the current proposal is parked at HIRO but could potentially become an LFDT project. The group also briefly mentioned an upcoming AI working group meeting scheduled for October 6th.
