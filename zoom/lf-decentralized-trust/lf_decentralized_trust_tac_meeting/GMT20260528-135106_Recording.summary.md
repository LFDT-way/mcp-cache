## Overview

The TAC meeting focused on reviewing project proposals and reports, with the main discussion centered on the Hyperledger Token SDK project's approval. The team discussed project naming conventions, with David explaining that the final name would need to pass trademark review and would not necessarily include "Hyperledger" as a prefix. The Token SDK project received sufficient votes to pass, and the TAC then reviewed reports for Paladin and Besu projects, approving both with minor feedback requests. The meeting also included a detailed discussion of the Smooth project's repository structure and documentation needs, with multiple TAC members providing feedback on improving GitHub organization, README files, and community engagement practices. Hendrik announced a Hiro Community Day event scheduled for July 7th in Bergen, which would take place before the We Are Developer conference.

## Details

### Hyperledger Token SDK Proposal

The team discussed questions about the Hyperledger token SDK project proposal, specifically addressing concerns about the project name and whether it should be prefixed with "Hyperledger." David explained that while the current temporary name includes "Hyperledger token SDK," the final project name will likely be different and will undergo trademark review through an outreach committee. The team clarified that the project name would not be generic like "token SDK" but would be a brand name, with several name options including bird and mythological references currently under consideration. The PR has crossed the 6-vote approval threshold, indicating it could be ready for passage, though the meeting continued to address remaining questions.

### TAC Mid-Year Updates Discussion

The meeting began with a motion being made by Diane and seconded by Marcus, which passed with unanimous agreement from all present members. Following this, Ry mentioned updates on the TAC mid-year and Trust Over IP's report, noting that Solang's grant had been accepted. Hendrik raised three topics for discussion, including feedback on AI guidelines for FFTT, a community event for the Highway Project, and the creation of an AI working group within LFTT. The group agreed to prioritize reviewing previously submitted reports, particularly the Paladin and Besser reports, before moving on to further discussions.

### Paladin Project Assessment Review

The team reviewed a project assessment for Paladin, a newly incubated project. Ramakrishna reported that while the project shows good community engagement, well-organized GitHub repositories, and proper documentation, it lacks a clear roadmap and some required badges. The group voted to maintain Paladin's incubated status and accepted the assessment report, with all members present voting in favor.

### Project Reviews and Community Updates

The team reviewed and approved Besu's graduation report, with Enrique providing positive feedback on the project's diversity of maintainers and achievements. For the Smooth project, the team identified several issues requiring attention, including missing documentation, inadequate repository structure, failing GitHub actions, and lack of releases or consumable artifacts. Weijia acknowledged the feedback and committed to addressing these concerns, including adding proper README documentation and breaking down large code changes into smaller, more reviewable pieces. Hendrik announced an upcoming HIRO Community Day on July 7th in Bergen, scheduled a day before the We Are Developers conference.
