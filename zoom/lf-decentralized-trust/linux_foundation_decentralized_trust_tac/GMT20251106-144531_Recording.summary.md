## Overview

The LF Decentralized Trust Technical Advisory Council meeting covered several key updates including newsletters, voting periods, and upcoming workshops, while also addressing project report approvals and open PR reviews. The meeting focused on two main task forces: the Contributor Ladder Task Force, which is developing a comprehensive documentation site for guiding maintainers and contributors, and the Project Consistency Task Force, which aims to create new guidelines documentation. The group discussed reorganizing the Contributor Ladder initiative under LF Decentralized Trust organization and addressed the need for new policies regarding late project reports.

## Details

### LF Trust Council Updates Meeting

The LF Decentralized Trust Technical Advisory Council meeting began with Tracy welcoming attendees and reminding them about the antitrust policy and Code of Conduct. She announced four key updates: the Dev Weekly Developer Newsletter, the ongoing voting period for the 2026 TAC term, an upcoming workshop on cross-network interop with Hyperledger Cacti, and the opening of Maintainer Days registration, which includes registration for the LFDT Member Summit. Tracy encouraged attendees to participate in these opportunities and provided links for further information.

### Project Reports and TAC Updates

The team discussed updates on project reports, with Tracy noting that several quarterly reports lacked sufficient approvals and requested reviews. Arun reported no updates on overdue reports, and upcoming reports for Soling and Firefly were highlighted. The group reviewed open PRs, including one to remove LFX insight scores from recommended tools, which received five approvals and was approved by Marcus, allowing Ryan to merge it. Tracy also presented updates to TAC chair notes, including a new section on agenda creation and distribution, and announced her decision to step down as TAC chair at the end of the term.

### Documentation Site Progress Update

The meeting focused on updates and progress related to two task forces: the Contributor Ladder Task Force and the Project Consistency Task Force. Diane provided an overview of the Contributor Ladder Task Force's progress, highlighting the development of a comprehensive documentation site aimed at guiding maintainers, contributors, and end users. The site is expected to launch by the end of November, though some content, such as security and operations guidance, is still pending. Diane requested feedback from TAC members and asked for input on where the documentation site should be hosted within the LFDT repository structure. Ry and Tracy discussed the approval process for the documentation site, and Ry expressed gratitude for Tracy's contributions to LF and Hyperledger.

### Reorganizing Contributor Ladder Initiative

The group discussed reorganizing the Contributor Ladder initiative under LF Decentralized Trust organization, suggesting a "Contributors" repo as a sister site to governance. Diane proposed creating a Contributor Strategy Working Group that would meet periodically to update guidance and develop better community development strategies for projects, potentially incorporating this into TAC quarterly reviews. The group also discussed renaming the initiative to "Contributor State" to reflect a broader focus on outreach and incorporating end users into project conversations. Matthew inquired about how this initiative would relate to formal maintainer and committer roles, with Diane clarifying that it would focus on recognizing and encouraging contributions rather than managing access rights.

### Contributor Site and Task Force Updates

The meeting focused on two main topics: the contributor site and the Project Consistency Task Force. Diane explained that the contributor site aims to help maintainers onboard new maintainers and provide templates for project structures. Tracy and Diane discussed the need to review existing content and determine what should be included on the site. Matthew presented a PR for the Project Consistency Task Force, which aims to create a new guidelines document. The TAC was asked to review the PR and provide feedback. The group also discussed implementing a new policy for late project reports, with Arun agreeing to notify projects about the policy and Diane offering to help with the Trust Over IP project.
