## Details

### CREDBL Platform Updates and Development

The CREDBL Community Call discussed the platform's recent updates, including new tags and debug logs for OpenID flows, as well as webhook changes for OID4. Krishna introduced CREDBL as an open-source decentralized identity and verifiable credential management platform, highlighting its multiple implementations and available documentation for developers. The team also mentioned ongoing work on cloud deployment, particularly for AWS, and encouraged participants to explore the documentation and get involved with the project.

### Token Management and OIDC Updates

The team discussed recent updates to token management and OIDC functionality. Sujit reported that token handling logic was improved to properly manage access tokens using refresh tokens across various applications. Tipu explained changes related to signer options in the presentation part, which now supports expiration settings. The team reviewed that these updates were implemented in the dev environment and were ready for testing in the Cuba environment.

### Unikernel Performance and Documentation Updates

Ramiz presented his findings on testing unikernels as a potential replacement for Docker in CREDIBL. He found that while unikernels performed well under low load, their performance dropped significantly under high load conditions. Ramiz also discussed his exploration of microVMs as an alternative, though he encountered issues with Node.js dependencies. The team agreed to expand the FAQ section in the documentation to include more common issues and components of CREDIBL. Ramiz will create an issue to track this documentation improvement.
