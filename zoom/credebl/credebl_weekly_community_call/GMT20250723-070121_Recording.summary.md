### Ethereum-Polygon DID Integration Demo

Ankita explained the integration of Ethereum and Polygon networks for DID (Decentralized Identifier) creation and schema management. She demonstrated how the system leverages existing Ethereum addresses and smart contracts to create DIDs, with schema hashes stored on the ledger and full schema files hosted on a file server. During the demonstration, there was an issue with uploading the schema due to low balance, which was resolved by changing the private key.

### Credible Integration and DID Document Updates

Ankita reported progress on integrating the Credible package, which is working for issuance and verification but has local testing issues. She mentioned that Ethereum ledger support for Credible has been added, and the team discussed the limitations of linked resources in the DID document, noting that attributes can be set but not linked resources. Rinkal suggested considering the cost implications of adding linked resources as new transactions on the ledger, and the team agreed to explore implementing this feature in the current live environment. Ankita planned to demonstrate the platform's functionality in the next call.
