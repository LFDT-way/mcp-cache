### Indy Project and Migration Updates

The Indy Contributors Call meeting on December 2nd, 2025 covered updates on the Indy project, GitHub migration, and IndyBase 2. Wade mentioned he had not reviewed a pull request for Indy and was occupied with other tasks, including materials for GitHub organization migration, and expected to resume work on the project next week. ### GitHub Migration for Indy Repos

The team discussed the GitHub migration work and its relationship to the 224R04 upgrade. Wade confirmed that there are approximately 18 repositories from the Indy side that need to be migrated, though he did not have the complete list with him. Stephen offered to share the repository list in a chat.

### Repository Migration to Non-Creds

The team discussed moving and archiving repositories, with a focus on Indy VDR which is the only actively maintained one. Stephen and Wade agreed to move the repositories to a new organization called "non-creds" while keeping the same repo names. Stephen mentioned that he and Andrew had previously worked on a plan to move credentials to a new organization, which included a list of steps that Wade had access to. The team also discussed the need to update GitHub actions to ensure workflows still function properly after the move.

### GitHub Cross-Posting Strategy Discussion

Stephen and Wade discussed cross-posting strategies for GitHub repositories, focusing on maintaining consistency in artifact deployment while minimizing the need for downstream projects to update their configurations. They agreed to keep the GitHub organization unchanged, except for potentially cross-posting images to both locations temporarily. Stephen mentioned ongoing work on automating the generation of maintainers files using a script based on Ry's Cloe Warden implementation, as well as plans to handle LFDT webpages and calendar invites.

### GitHub Redirect and Naming Discussion

Stephen and Wade discussed the process of redirecting GitHub pages and publications, noting that GitHub pages do not redirect properly. Stephen proposed creating an issue to address this and suggested using "Hyperledger-Indy" as the organization name, as "Indy" is already taken. They agreed to keep "indy-" in the front of each repository name.

### GitHub Migration Project Update

The team discussed the GitHub migration project, where Rye has already created the new organization and some archived content has been transferred. Stephen offered to create a list of repositories without GitHub actions to be moved, while Kim committed to updating the team on Discord about the migration progress. The conversation ended with a brief mention of Indy Besu and DID WebVH, noting that Renata was absent to provide updates on those topics.

### DidSkid Project Progress Update

Stephen discussed upcoming meetings and progress on the DidSkid project. He mentioned that Patrick St. Louis has made significant progress on the VH Server, which will be demonstrated tomorrow. The demo will showcase a full flow of using traction to create DIDs, on-creds objects, and issue credentials to a BC wallet. Stephen also mentioned that final plans are being made for migrating issuers and verifiers.

### MPM Publishing and Toolchain Updates

The team discussed updates on MPM publishing and verified publishers, with Stephen confirming that the V44.4 work was completed three weeks ago and the toolchain upgrades, including React Native and wrapper version updates, were merged last week. Kim ended the conversation with no additional updates to address.
