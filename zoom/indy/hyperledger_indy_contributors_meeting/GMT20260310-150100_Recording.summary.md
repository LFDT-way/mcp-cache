## Details

### Annual Report Maintenance Concerns

The meeting focused on feedback received regarding the annual report, with concerns raised about the lack of maintenance, releases, and vulnerability fixes for dependencies. Stephen reported attending a recent meeting where these issues were discussed, and while no formal vote was taken, the possibility of moving out of graduated status after 2026 was mentioned if improvements are not made. The discussion also touched on the potential for pushing non-creds into graduated status, though this was not the primary concern.

### Indy Node Build Environment Updates

The team discussed issues with Indy Plenum and Indy Node deadlocking on Kim's new AMD-based machine. Kim recommended adding ARM64 support for Indy Node, but noted this would require addressing dependency issues first. The group agreed to push forward with a bare-bones Ubuntu 20.04 release to establish a working build environment rather than waiting for complete dependency updates. Kim will move forward with the upgrade path and reach out to Wade regarding repository issues, while noting that dependency updates are needed before implementing ARM64 support.

### First Person Project Updates

Stephen provided updates on the First Person project, including the publication of Helm charts and a recent demo for the Linux kernel group. He discussed plans for updates to the DID resolution spec and potential changes to DID WebVH, including considerations for post-quantum support. Stephen explained how post-quantum keys and signatures might affect log file optimization strategies. He also informed the group that the ARIES info website domain had lapsed, and the OWL tests are now available at a new GitHub pages location.

### Agent Test Harness Meeting Update

Kim announced an upcoming Agent Test Harness Meeting scheduled for Thursday at 9am Mountain Time, though noted the meeting still had an old name. Nathan attended the conversation to catch up on the community project after being away. The conversation ended with plans to reconvene in two weeks.
