Kim welcomed participants to the August 25th, 2026 Indy Contributors Call and mentioned that the meeting would focus on the Ubuntu 22.04 upgrade. No additional topics were discussed, and Kim confirmed there were no further agenda items from Lynn.

### Ubuntu 2204 Docker Implementation Plan

Kim presented the plan to upgrade to Ubuntu 2204 using a Docker implementation only, which will involve Indy Plenum and Indy Node producing Docker images. The new approach aims to simplify the release workflow by eliminating the use of Debian packages and reducing overhead. Kim demonstrated a working build in a local environment, showing that all tests are passing, and mentioned that the next steps involve moving the process to the Indy Node environment and working on triggering the correct actions.

### Manual Upgrade to Docker Containers

Kim explained that the upgrade from 20.04 to 22.04 will need to be manual due to the switch to Docker containers. Kim outlined a future upgrade mechanism involving sending a signal to stop processing, relying on Kubernetes or Docker to fetch the latest image on startup, and configuring a Docker repository with a labeled "latest" image. Lynn acknowledged this would result in a several-month upgrade timeline for the network.

### Docker Compose Upgrade Discussion

Kim discussed the upgrade process, hoping to use Docker Compose for an in-place upgrade to avoid a lengthy multi-month process. Lynn acknowledged the challenge would be coordinating manual processes across different node operators. Kim mentioned working on Indy node builds and provided a status update on the process.
