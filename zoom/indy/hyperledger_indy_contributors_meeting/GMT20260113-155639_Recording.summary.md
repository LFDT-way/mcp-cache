## Details

### Indy GitHub Migration Status Update

The Indy Contributors Call discussed the ongoing GitHub migration to the Hyperledger Indy organization, with Kim noting that the Ubuntu 2204 upgrades need to be completed before the migration is finished. The meeting also touched on the status of Indy Besu, though no specific updates were provided. Kim reminded attendees about the Linux Foundation's antitrust policy and Code of Conduct, as well as the Decentralized Trust Code of Conduct.

### Indy Project Migration and Updates

Renata discussed the successful migration of the Indy repo and mentioned that resources are being allocated to update repository pipelines, packages, releases, and libraries. She expressed gratitude to CPQD and SERPRO for their contributions and highlighted that Brazil companies now have revocations in a full normal format. Renata also mentioned that CPQD prepared a press release about using Indy Bezo in production and is planning a meetup, likely an LFDT meetup, about Indy Bezo in production. She expressed hope to hear from Matthias about technical details and use cases and mentioned that Alexander Sherbakov will present updates and the roadmap for Indy Bezo at the LFDT membership summits in January. Renata concluded by noting that discussions about Indy and AI at conferences indicate that the Indy Project is still active and in use with AI applications.

### GitHub Migration Update Complete

Stephen provided an update on the GitHub migration work, explaining that all repositories were moved from Hyperledger to Hyperledger-indy GitHub Organization. He noted that one repository was left in Hyperledger as a redirector for GitHub pages, and most PRs were successful, with only a few issues related to outdated Rust versions. Stephen also mentioned that artifact locations, such as GHCR and NPM, remained unchanged, allowing the community to decide if and when those should be updated.

### Ubuntu Upgrade and Open Source Plans

Stephen completed the Ubuntu 2204 upgrade and confirmed it was successful, with no major issues. Kim appreciated Stephen's support in the community and confirmed they could proceed with the upgrade. Renata mentioned plans to publish open-source wallets and an agency for issues and verifiers, which would work with various projects including Identity Hub and Indy. Kim noted they would add links to the published resources once available. Kim also mentioned they needed to further investigate the Indy Plenum and IndyNode tests.

### DID Web Community Updates

The meeting focused on updates regarding the DID Web community and a new DID method called DID-Sel. Stephen mentioned that Manu would join the upcoming DID WebDH call on Thursday to discuss DID-Sel and other related topics. Kim inquired about the timing of the call, and Stephen provided the agenda details. No other topics were discussed, and the conversation ended with plans to reconvene in two weeks.
