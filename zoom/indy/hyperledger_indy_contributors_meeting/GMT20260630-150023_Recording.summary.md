## Overview

The meeting focused on the Ubuntu 22.04 upgrade progress and technical changes to the package management system. Kim announced plans to switch from Debian-based packages to Docker configuration to address fragile Python package workflows and simplify development processes. The transition requires manual upgrades from current nodes to the new Docker-based system, which will also support future Kubernetes installations. Kim noted that while this change affects all node operators who must manually upgrade their servers, it will enable better development environments and support for containerized deployments. ### Docker Configuration Upgrade Discussion

Kim and Lynn discussed the need to switch to a new Docker-based configuration before performing an upgrade, which will require manual configuration steps for node migration. Kim explained that the motivation for this change is to address fragile Debian package tooling for Python packages, which has been causing issues with repository updates and build processes. The new configuration will also enable easier installations in Kubernetes environments, though automatic upgrades would still need manual node restarts in Kubernetes.
