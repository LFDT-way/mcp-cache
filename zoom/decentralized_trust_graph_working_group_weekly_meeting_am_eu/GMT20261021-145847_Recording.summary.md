## Details

### Decentralized Trust Graph Working Group

Drummond opened the October 21st meeting of the Decentralized Trust Graph Working Group, a joint working group of Cross-ORP and DIF. The meeting began with discussions about a recent PHP security vulnerability affecting many websites, including government sites and the Rotterdam port. Drummond announced upcoming events including the Internet Identity Workshop and the SETI Summit, and mentioned that task force reports would be presented during the meeting.

### Version 0.10 and VTA Updates

Erika announced the release of version 0.10 with an NPM package now available for installation, though work continues on open sourcing reference apps like the Agent app. Geoff presented his new VTA Farm site, which is based on Kubernetes and allows hosting multiple VTAs. Drummond shared insights from a recent Green Build conference presentation about integrating Decentralized Trust Graphs with Knowledge Graphs in smart building applications.

### CA Breach and Updates Discussion

Vikas raised concerns about a recent CA breach involving E. Mudra's root certificates and discussed potential alternative solutions for CAs based on their current work. Mitchell shared updates about attending the BGIN conference and deploying a BTC majors.city website, which includes a wizard for setting up VTC and agent runtime features. Drummond announced that the team will present highlights at the upcoming October meeting and requested task forces to submit slide presentations, with the meeting scheduled for next Wednesday from 2-3:30 PM Pacific time.

### Upstream Convergence Progress Update

Sankarshan reported good progress on upstream convergence work, with basic scaffolding in place and downstream toolkit input being synthesized using AI, expected to be ready within a week. The Prudential Task Force meeting was deferred to next week due to low attendance, with Drummond confirming he will attend next week's meeting. Drummond highlighted a node-type discussion proposal that started with six fundamental characterizations of nodes and requested team review and feedback on the proposal.

### Trust Task Alignment Discussion

The team discussed the growing number of trust tasks on trustask.org, which has reached 733, and reviewed upcoming VTC functionality including group management, identity management, and polling/voting features targeting the next release after Eucalyptus. Brendan and Alberto from Keyring raised concerns about trust task alignment across different implementations, emphasizing the need to ensure consistent language and API usage across various stacks to maintain interoperability. The group discussed the possibility of establishing a trust task force to address alignment issues and potentially develop conformance test suites for interop, with Brendan planning to attend IIW to further discuss these topics.

### Task Force and VTI Updates

The meeting covered updates from multiple task forces and project developments. Drummond suggested repurposing the Credentials Task Force meeting to also serve as Trust Task Force discussions. Mitchell raised questions about implementing terms and conditions functionality, with Glenn explaining that trust tasks should be generic and suggesting a partial acceptance approach for community members. Glenn then demonstrated new features coming in the next VTI stack release, including a Git repository manager, membership directory, groups functionality, and data rooms, all built as independent sidecar applications. The team also discussed upcoming community voting features and plans for future developments.
