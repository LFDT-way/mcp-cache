### AI Knowledge Base Architecture Overview

Lochan explained the architecture of their AI system's knowledge base, which processes various data types including YouTube transcripts, web content, and documents. The system uses a data ingestion pipeline to handle different file formats and applies metadata-based similarity search for security and access control. Lochan described how the system tags and chunks documents, converts them into embeddings using Mistral or OpenAI models, and stores them in a vector database (HiS) for later retrieval. The unified knowledge base allows users to perform complex queries across multiple modalities while maintaining document security through metadata-based access control.
