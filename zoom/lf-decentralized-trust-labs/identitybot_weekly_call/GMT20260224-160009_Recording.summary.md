## Agenda

This is a recurring call for the IdentityBot Lab. It's open to anyone interested in Identity Agents. The focus varies each week. See this week's agenda at https://github.com/LF-Decentralized-Trust-labs/identity-bot/tree/main/calls
An Identity Agent is a deterministic, private server that protects users' rights by giving them programmatic control of their digital identity. It runs as a server on a cell phone, desktop, or a private cloud server (Secure Enclave with TEE).

## Details

### Identity Agent Cross-Platform Demo

Robert demonstrated the first Identity Agent, which he had developed for Linux, macOS, Windows, iOS, and Android platforms. He showed the installation process on Linux and briefly mentioned that he had also created versions for other operating systems.

### Identity Creation and Interface Testing

Robert discussed the process of creating a new identity and encountered some bugs while testing the functionality. He noted that the interface behaves differently when setting up for an individual versus an organization, requiring additional logic to account for these differences.

### Identity Agent Seed Phrase Security

Robert discussed the process of creating a new Identity Agent, emphasizing the importance of securely storing the seed phrase, which serves as the only backdoor for resetting and rotating cryptographic keys. He mentioned the option to save the seed phrase to an NFC tag or download it, while noting the associated risks. Robert also highlighted a warning system in place to remind users of the potential consequences of not verifying the seed phrase during setup.

### Contact Addition via QR Code

Robert demonstrated how to add contacts using a QR code on a Linux server dashboard and an Android phone. He showed the process of scanning a QR code to add a contact, which he described as the easier method.

### Profile Contact Feature Testing Discussion

Robert discussed testing a contact feature in a profile, noting that he had not tested it yet and was unsure if it was related to an alerts section. He mentioned that the feature might be linked to a URL and the use of Cloudflare for creating tunnels to enable contact through a specific URL.

### Identity Agent Cross-Platform Demo

Robert demonstrated the Identity Agent's functionality across multiple platforms including Mac OS, Windows, Linux, iOS, and Android. He explained the option to migrate backend processing to an external server and discussed the choice between keeping signing keys on the phone or a separate server. For the coming week, Robert plans to enhance contact management features and add support for importing contacts from third-party services like Google and iCloud.
