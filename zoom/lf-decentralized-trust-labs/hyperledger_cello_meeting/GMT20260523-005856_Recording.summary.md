## Details

### API Engine 和 Dockerfile 升级讨论

会议讨论了API Engine和Dockerfile相关事宜。Haibo提到API Engine版本为3.8，child agent版本为3.13，目前CI已升级到3.11，考虑是否需要完全升级到3.13。Baohua建议可以尝试使用AI工具来简化升级过程。

### Azure CI问题讨论会议

团队讨论了Azure CI中的重复问题，Haibo建议删除相关部分。Baohua指出GitHub Actions最近有稳定性问题，建议团队尽量使用GitHub Actions而不是其他选项。会议最后，Baohua建议继续使用GitHub Actions来解决问题。

### 代码合并和分支管理讨论

Yu-Lin和Haibo讨论了代码合并和分支管理的问题，Yu-Lin不确定是否使用正确的dashboard。Haibo表示会后续运行检查查看情况。讨论中提到了PR审查和版本升级相关事宜，Yu-Lin提到应该升级到24版本以避免频繁更新。

### AI内容质量合并讨论

Yu-Lin表示由于AI生成内容的质量问题，目前无法确定是否能进行merge，并提到需要确保内容质量。Baohua建议可以将质量不好的内容提交给相关人员 review，并询问是否有自动 review 功能。Haibo回应说自动 review 已经配置，但有时还需要手动处理。会议最后，Yu-Lin提到由于刚开始新工作在IBM，时间有限，可能无法参与太多讨论。

### 银行部署技术讨论会议

Baohua和Yu-Lin讨论了在银行部署事宜，Baohua提到IBM研究中有很多新技术但进展会比较慢。Haibo确认没有其他事项需要讨论，Baohua要求Haibo添加评论并使用3.1版本作为长期稳定版本。Baohua还讨论了新出的模型，包括谷歌的3.5版本，认为速度快但效果一般，目前主要使用cc和codec进行代码生成和审查。
