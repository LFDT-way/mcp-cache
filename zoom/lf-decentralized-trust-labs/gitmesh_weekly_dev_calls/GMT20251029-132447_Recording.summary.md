## Details

### Gitmesh Open Source Project Overview

The team practiced their presentation for tomorrow's community session about Gitmesh, an open source project under LFDT Trust. ### GitMesh Contribution Setup Tutorial

Gagan demonstrated how to start contributing to GitMesh by forking the repository, cloning it locally, and setting up the development environment using PNPM. He explained the project's technology stack, including TypeScript and the Web Container API, and highlighted the importance of the contributing.md file for guidance. Gagan also encouraged participants to join the LFX Discord server for community engagement and mentioned weekly dev calls.

### Modular UI Architecture Overview

Mittal presented on the modular UI architecture, explaining the overview section that displays GitHub activity and project details, as well as the settings and notification sections. He detailed the use of Remix for file-based routing and React components for modularity, emphasizing automatic design and feature slice organization to facilitate contributor contributions. Mittal also covered data flow and state management, highlighting the use of Remix loaders and actions for server-side rendering and client-side state, and discussed the UI framework and accessibility using Tailwind CSS and VADIX UA.

### GitMesh Security System Overview

Anubhav presented a detailed overview of GitMesh's security system, explaining their use of OAuth2 authorization code flow with Pixie and JSON web tokens for stateless authorization. He discussed token storage methods, including the use of HTTP-only secure cookies for refresh tokens and direct storage in client memory for access tokens. Anubhav also covered token validation processes, refresh token flows, and security protocols such as rate limiting, content security policies, and HTTP Strict Transport Security. Additionally, he mentioned measures to protect against CSRF attacks, injection attacks, and sensitive log handling to ensure a secure workflow.
