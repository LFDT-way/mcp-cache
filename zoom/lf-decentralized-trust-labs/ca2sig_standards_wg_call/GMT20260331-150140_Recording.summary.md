## Agenda

The biweekly Standards Working Group has been defining a set of ontologies that enables the description of anthropogenic impact following W3C semantic web guidelines. 
The public release of four interrelated ontologies in OWL, JSON-LD and TTL format is planned for the third quarter of 2025. 
We foresee the use of the ontologies in data models, MRV systems, and AI-assisted applications.
Anyone is welcome to join.
The call will take place every other Tuesday at 8 AM Pacific Time.
More about the Standards group is at: https://wiki.hyperledger.org/display/CASIG/Standards+WG

### LLM Guide Ontology Updates

Alex presented updates on his work on the LLM example guide, which resulted in creating new classes and properties for the main iOontology and Impact Ontology. He explained the addition of the "indicator value" class to allow for describing the source of values and the introduction of "comprises state" to formally define nested states. Alex also mentioned relaxing the "governs" and "is governed by" properties to allow them to be used with controls other than roles.

### Ontology Governance and LLM Example

Alex discussed changes made to the ontologies to allow for proper governance restrictions, particularly for roles, activities, and objectives. They completed an LLM example using EcoRegistry, which resulted in a comprehensive JSON-LD model spanning 864 lines. The example, including prompt examples and manual changes made to the LLM's output, was added to the community registry's wiki under Resources for others to reference.

### LLM Industrialization for Ontology Visualization

The team discussed the industrialization of using LLMs for ontology visualization and annotation. Alex shared his experience using ChatGPT for this purpose, noting that with proper guidance, the LLM could learn and suggest best practices. Christiaan suggested developing a library of prompts and context to make the process more deterministic. Alfonso proposed using knowledge graphs to structure the data and measure progress. The group agreed to prepare a practical exercise in a future meeting where they would go through an annotation process together using a new document or focus area. They also noted the need to establish abbreviation conventions for their work, particularly regarding ontology suites.
