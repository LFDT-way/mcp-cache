## Agenda

The biweekly Standards Working Group has been defining a set of ontologies that enables the description of anthropogenic impact following W3C semantic web guidelines. 
The public release of four interrelated ontologies in OWL, JSON-LD and TTL format is planned for the third quarter of 2025. 
We foresee the use of the ontologies in data models, MRV systems, and AI-assisted applications.
Anyone is welcome to join.
The call will take place every other Tuesday at 8 AM Pacific Time.
More about the Standards group is at: https://wiki.hyperledger.org/display/CASIG/Standards+WG

### HTML Redirects Implementation Progress

The team discussed the implementation of HTML redirects for their ontologies and confirmed that all redirects were working correctly on the test server datadiz.xyz. Christiaan demonstrated that the JSON-LD, Turtle, RDF/XML, and HTML formats were properly implemented, and they were one commit ahead of W3ID.org. The team agreed to submit a single pull request for the four directories containing the HD access files, which specify content negotiation. Alex suggested creating release branches for their ontologies, and the team decided to proceed with opening the pull request and creating release branches simultaneously, as Independent Impact was ready for production.
