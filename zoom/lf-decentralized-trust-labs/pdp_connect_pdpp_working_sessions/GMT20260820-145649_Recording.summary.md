## Details

### PDPπ Data Management Planning

Tim led a session on PDPπ, discussing data consent, storage, and serving methods in preparation for the upcoming GDC announcement of version 0.1. The previous sessions covered architecture and client data access requests, with data being modeled as either mutable or immutable for optimization purposes. The next session will focus on governance, led by Art from the Bonnet Foundation.

### PDPπ Grants Core Concept Overview

Tim explained the PDPπ standard's core concept of grants, which are immutable records of data access permissions that include details about access scope, terms, and specific data fields. He described how grants support both one-time and continuous access with cursor-based pagination for efficient data synchronization, and noted that while grants are immutable, users can revoke future access. Tim also outlined key limitations of the current version, including restricted query capabilities for clients compared to owners, and mentioned that future extensions may address these limitations and expand policy options.

### Subgrants and Data Synchronization Discussion

Carman from Mozilla asked about the concept of subgrants in the current specification, and Tim acknowledged it as an open question that could be valuable but hasn't been a focus yet. Lisa informed Tim about an overlapping IETF draft on RAR metadata and mentioned existing standards like WebDAV and cursor-based protocols that could be relevant for data synchronization. Tim expressed optimism about developing a bridge solution that could work with existing systems rather than requiring complete overhauls.

### Grant Protocol Authorization Discussion

Tim discussed the protocol's flexibility regarding grant approvals and authorization methods, noting that future versions could support AI agents for delegating approvals. Carman raised a question about handling changes in legal ownership of data access permissions, which Tim acknowledged as an important gap to address. Lisa mentioned the ISO My Terms standard as a relevant approach for user data hosting terms. The next session will be led by Art, focusing more on governance and policy aspects.
