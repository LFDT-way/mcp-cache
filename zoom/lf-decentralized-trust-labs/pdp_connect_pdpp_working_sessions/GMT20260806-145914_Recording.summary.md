### PDPPI-Connect Data Portability Standard

The team introduced the PDPPI-Connect standard, a proposed shared language for data portability similar to X.402 for payments and MCP for data import. Anna explained that the standard aims to enable granular access to personal data across different platforms, allowing users to selectively share specific data rather than entire data exports. The team outlined a four-session series for August covering introduction and architecture, record model, grants and connectors, and resource server, with plans to launch at Geneva in September.

### PDP Data Portability Standard Presentation

Tim presented PDP (Personal Data Portability) as a unified standard for data portability, explaining how it builds on existing OAuth authorization protocols used in medical records and banking. He demonstrated how PDP allows users to grant access to specific data slices through an immutable grant system, with existing data connectors already supporting platforms like ChatGPT and Aura. Tim emphasized that PDP is not opinionated about identity, storage, or deployment methods, and invited feedback through their Discord channel and GitHub repository, particularly seeking API partners to pilot the protocol.

### Data Privacy Standards Discussion

The team discussed technical and policy aspects of data privacy standards, with Sara raising questions about latency and real-time data exchange mechanics similar to UK Open Banking. Tim explained that PDP's active API allows for continuous data access and updates using existing consent, while Anna noted that the standard intentionally leaves storage implementation underspecified, suggesting a federated system with personal servers as a practical approach. Justin raised concerns about data sovereignty requirements in the EU and potential government data subpoenas in a user-controlled environment.

### Data Custody in Decentralized Systems

Anna and Justin discussed the legal implications of data custody in a decentralized system, with Anna explaining that users would retain control over their data similar to non-custodial wallets. Justin suggested this approach could help prevent governments from claiming control over the entire network, particularly addressing concerns about Chinese government jurisdiction over users. They agreed that the decentralized nature of the system would limit jurisdiction to individual users based on their current location rather than the entire network.

### PDP Website Self-Hosting Demo

Tim demonstrated the PDP website's self-hosting option and showed how it allows users to connect personal data sources to AI agents with specific access controls. He explained how the system can provide semantic search capabilities across data streams and discussed potential extensions to the protocol. Daniela shared insights from previous data portability work, noting that being less opinionated may have hindered adoption, and suggested that current incentives might be more favorable due to changing platform dynamics and new tooling available to smaller organizations. The group discussed connecting with Jack Dorsey's team and mentioned an upcoming event in Geneva where the team plans to formally launch their work.
