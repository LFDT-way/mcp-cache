## Details

### Restructuring Identus Documentation Website

The team discussed plans for the second version of the Identus documentation website, which will restructure content into three main categories: Learn, Developers, and Technical Reference. Javier presented a roadmap for improvements based on internal feedback, including better navigation and the removal of duplicate content. The team also discussed potential changes to the TypeScript SDK, including making it a monorepo and adding support for cloud agent API clients and React Native components. Javier mentioned that further improvements to website indexing and content sharing would be announced in the coming weeks and months.

### Linter Replacement with Biome

Javier and Roberto discussed replacing the current linter with Biome, which Javier confirmed was likely to happen due to its out-of-the-box performance and integration with tools like VS Code. They agreed to create a GitHub ticket for this transition, which would also allow for CI pipeline integration to enforce formatting and linter rules. Javier mentioned that this change would be part of a broader modernization effort for the TypeScript SDK over the coming months, including moving to multiple packages and adopting a more modern approach.

### VDR Integration and Driver Progress

The team discussed progress on the VDR (Virtual Data Room) and its integration with the Identus platform. Fabio reported finding a new bug related to event validation and is working on fixing it while also improving blockchain state management. Pat shared updates on driver integration, including progress on the in-memory and database drivers, and mentioned plans to phase out the Prism node in favor of EOP Zoom. Javier inquired about the Catalyst proposal's current phase, but no specific information was provided in the transcript.

### Workshop Planning and Credential Verification

The team discussed scheduling a workshop and agreed it could be part of a community call with at least one week's notice. Roberto raised a question about enabling agents to verify credentials using DITCOM channels, which Javier explained was technically possible but would require careful consideration of security implications. The group explored the possibility of integrating tools with MCP and discussed a proof of concept project involving a lightweight browser-based model that could use Identus and SSI for credential verification. Javier also shared his work on creating a synthetic dataset from the TypeScript SDK to help with documentation and code understanding.
