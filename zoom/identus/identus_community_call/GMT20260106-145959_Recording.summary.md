## Details

### Identos 2026 Roadmap Draft

Yurii presented the draft of the Identos Roadmap, outlining five key initiatives for 2026. These include releasing ID and proof of humanness for Discord, enhancing Midnight's SSI capabilities, developing a solution for universities in Mexico, maintaining and adopting the Identos platform, and focusing on platform excellence through code quality improvements and certifications. The team plans to collaborate with various groups, including the Lace team, Midnight team, and community, to deliver these initiatives. Yurii invited feedback and encouraged everyone to review the draft and add any missing information.

### Identos Platform Integration Discussion

The team discussed the integration of the Identos platform with the Lace wallet, focusing on a proof-of-humanness system using the DIDIT platform. Fabio raised questions about the openness of the technology and potential community use cases beyond the current Discord integration. Roberto inquired about the KYC process and assertion levels, which Fabio explained would be handled by an external system. Yurii emphasized the need for a generic solution that could be adapted for various use cases. The team also discussed plans to make Midnight verifiable credential components production-ready and integrate them into the Identos platform.

### SSI Integration with Midnight Blockchain

The team discussed the integration of SSI with Midnight blockchain, focusing on a new DID method that enables developers and identity wallet users to create Midnight identities using W3C verifiable credentials. Yurii explained that the credentials leverage Midnight's compact language with built-in zero-knowledge proof capabilities, allowing for private data storage while maintaining public accessibility through smart contracts. Shailesh clarified that while the cryptography is optimized for performance within the circuit, all verifications remain private by default, with proofs being created by a proof server and validated by chain validators. The discussion concluded with Fábio noting that the main goal of this implementation is to treat credentials as first-class citizens on the blockchain.

### Platform Roadmap and Integration Planning

The team discussed the roadmap for the Identus platform, focusing on consolidating existing features and improving documentation. They highlighted the need to make the Verifiable Data Registry (VDR) production-ready and integrate it into the platform. Fabio suggested exploring AI-assisted deployment tools for easier setup. Yurii mentioned ongoing work with Midnight components and the potential for one-line deployments using NixOS. The team agreed to continue refining the roadmap and welcome feedback on potential new features or capabilities.
