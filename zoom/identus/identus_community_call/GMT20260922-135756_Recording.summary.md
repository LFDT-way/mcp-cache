## Details

### Identus Project Rust Development Updates

Javi provided updates on the Identus project, explaining they are using Rust to unify the codebase and avoid duplicating development efforts. Javi also discussed progress on the identity OSID, highlighting their achievement of verifying credentials and claims within smart contracts, with an example of locking and unlocking funds based on identity verification. The meeting was ongoing, with Javi waiting for additional participants to join.

### TypeScript SDK Mentorship Program Updates

Javi provided updates on the mentorship program, which aims to build a unified UI for the TypeScript SDK and Cloud Agent. The program has made significant progress, with features like schema and deed creation, publishing, deactivation, and updates implemented for both cloud and local agents. The team is currently working on restructuring the application into multiple pages and plans to complete additional phases, including out-of-band presentation URLs, verification flow, and extensive cloud agent testing. Javi expressed confidence in closing the project in the coming weeks and mentioned plans for Sadie to present a recording on using the service and organizing a workshop for the community.

### Hyperledger Identus Development Updates

Yurii reported that they submitted a technical committee report for Hyperledger Identus which is currently under review and requires additional meetings with Linux Foundation Decentralized Trust. The team is planning to deprecate Prism Node by the end of 2026, with a full deprecation in the platform release that will include Neo Prism instead. They are also developing Rust SDK packages that will be compliant with Apollo project cryptography and include PrismDid method implementation and VDR implementation as reusable components.

### UNIFI and Software Factory Updates

Yurii confirmed that UNIFI is planned but will start with grades first. He mentioned that they recently created a secret with Linux Foundation admins and will begin publishing three specific packages that are meaningful for Neoprism. Pat is working on implementing a software factory for the Identus platform, which will help automate PRs and address cross-cutting concerns, though they expect to wait at least one to two weeks before fully implementing this system.

### SDK Unification and Project Updates

Javi expressed excitement about unifying the SDK into one source of truth, which Yurii confirmed is possible with AI though it would take time. Jon provided an update on a book project nearing completion, explaining it covers current releases including Prism Node and is intended for technical beginners. The team is actively seeking feedback to incorporate into their Catalyst project, though they are currently struggling with the deadline and unsure of the best way to collect feedback.

### Book Workshop Planning Discussion

Javi proposed organizing a workshop for the book with exercises and feedback sections. Jon shared information about open-source repositories including example projects for iOS, Android, and web, and mentioned they need to publish the book by the end of the month to meet the Catalyst deadline. Javi suggested involving Sadie, who has been working on the Identity Portal, in providing feedback on the book, and Jon agreed to share the book in the general Discord chat for team review.

### Cloud Agents Document Signing Update

Jon presented an updated book on using cloud agents for document signing and verification, which is now published online but needs official recognition for the Catalyst program. The team discussed plans to update the book's content, particularly regarding the deprecation of PrismNode, and Jon requested feedback through GitHub issues. Seydi reported progress on phase 5 work and mentioned an upcoming pull request, while Javi confirmed the project is on track to complete in the next 2-3 weeks with only verification flow and end-to-end testing remaining.
