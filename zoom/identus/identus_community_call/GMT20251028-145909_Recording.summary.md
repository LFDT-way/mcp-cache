Alan was set to present an overview of the integration project, which aims to create a new method specification. The team emphasized the importance of reading the antitrust policy and Code of Conduct before the meeting.

### Integration Dashboard Release Updates

Allain presented updates on the integration repository dashboard, noting that the release page was previously broken but is now functional with working typescript, swift, and service components. He shared a mock design for the releases page, which will display new releases as cards showing platform releases and associated versions. ### Automated Release and Integration Testing

The team discussed setting up automated release processes and integration testing. Allain explained plans to add a GitHub workflow trigger that will automatically create cards showing release components' status when new releases are made. Fabio and Yurii raised questions about selecting specific component versions for testing, and Allain agreed to implement manual triggering capabilities for this purpose. Yurii then presented an update on Identos' work with Midnight Network, including their development of Midnight DID method specifications, TypeScript libraries, and a Referable Natural Oracle demo that uses Git Prism for issuing credentials compatible with Midnight smart contracts.

### Integration Dashboard and Release Planning

The team discussed the integration dashboard, with Yurii suggesting they need to experiment with it to determine how it can support their release activities. Allain acknowledged the need to allow releases of individual components while maintaining compatibility with the latest components. Fábio proposed switching the meeting schedule from weekly to bi-weekly, given the reduced activity and end-of-year considerations, and agreed to consult the community on Discord for feedback.
