## Overview

In this meeting, Pat and Yurii introduced Neo Prism, a new Rust implementation of a Prism node under the Hyperledger Identity Project that offers significant improvements over the original Prism node, including a smaller Docker image, faster processing, and better resource management. The team explained that Neo Prism supports various DLT sources including Aura and DB sync, can be deployed in multiple modes, and provides more efficient database queries that only target relevant transactions rather than scanning millions of blocks. They discussed future plans including deprecating the original Prism Node by year-end, potential WebAssembly integration, and encouraged everyone to test Neo Prism and provide feedback.

### Neo Prism Rust Implementation Launch

Pat announces that Neo Prism, a Rust implementation of a Prism node, is now officially under Hyperledger Identity Project. The implementation can resolve and publish data to the blockchain in W3C format, with documentation and artifacts available on Docker Hub and public instances accessible for testing. Neo Prism can be deployed in multiple modes (indexer, submitter, or both) and supports various DLT sources including Aura and DB sync, with conformance tests ensuring it matches or exceeds the capabilities of the original Prism node. Yurii adds that Neo Prism addresses resource consumption issues of the original Prism node, which previously relied solely on DB sync for retrieving Atala operations.

### Cardano Indexing and SDK Development

Yurii explains that Aura uses public Cardano speeds and with Demeter's free tier, users can index the full Cardano blockchain without running the entire stack or allocating many resources. Pat confirms that indexing with DB Sync takes only about 30 seconds, making it suitable for enterprise or private deployments that need private resolvers. Yurii highlights that the new Prism, written in Rust, has a smaller Docker image (around 16MB according to Pat) compared to the original Prism Node's 500MB, opening opportunities for private deployments without allocating significant resources. He also mentions they're investing in SDK development to support various operations using Blockfrost API, allowing for non-custodial solutions without needing heavy infrastructure services.

### Cardano Metadata Integration for Neo Prism

Roberto asks if the new div format for result spawns allows for freeform metadata, specifically to include transaction addresses and other information when resolving data stored in Cardano. Yurii confirms this feature can be added to neo prism in a couple of weeks, explaining that while transaction IDs can't be returned immediately upon submission, they can be retrieved once the transaction is indexed in the blockchain. Pat receives praise for the improvements, and Yurii mentions discussions about integrating a neo prism client into the Cloud Agent.

### Neo Prism Integration Strategy

Yurii suggests deprecating the prism note and creating a neo prism in the integration project that would include all SDKs and components together, which would involve sharing configuration and docker files for testing use cases with SDKs and blockfrost. He also proposes creating a WebAssembly bundle from the Rust codebase with TypeScript SDK components, which Pat confirms should be theoretically possible if they're not using incompatible libraries. Roberto acknowledges that compiling WebAssembly models can be challenging but agrees that Rust to WebAssembly conversion should work.

### Neo Prism Database Optimization

Yurii explains that Neo Prism is a new implementation that improves upon the original Prism Node by optimizing database queries, particularly during bootstrap time. He details how the old Prism Node performed full scans of millions of blocks without filtering, while Neo Prism uses a more efficient approach to query only the relevant transactions. Pat confirms that Neo Prism uses the same database with the chain history but processes queries much faster, with Yurii committing to deprecate the original Prism Node by the end of the year. The team encourages everyone to try Neo Prism and report any issues.
