## Details

### Linux Foundation Mentorship Selection

Yurii announced that Sadie was selected as a mentee for the Linux Foundation decentralized trust mentorship program, with 118 applications processed down to 78 active applications and finally selecting five mentees. The team is now in the mentorship onboarding phase where they will discuss rules, milestones, and collaboration processes with both Linux Foundation and Sadie. Additionally, Pat confirmed that the platform release version 2.17 has been completed, fixing NPM publishing issues and including releases for all three SDKs.

### SDK Release and Compatibility Updates

Yurii provided an update on the SDK release process, explaining that they are waiting for SDK releases and will run compatibility tests, expecting the process to take 2-4 weeks in the worst case. He discussed challenges with PR reviews, noting that due to limited capacity and the need to maintain platform stability during stabilization and release processes, they are temporarily slowing down PR releases. Yurii also highlighted concerns about performance optimizations in the Pluton code, emphasizing the importance of having evidence of performance issues before implementing changes and maintaining consistency across their three SDKs.

### Rust SDK Development Planning

Pat advised that security issues should be reported privately through email or Discord direct messages rather than publicly on GitHub. Yurii discussed plans for developing a Rust SDK, explaining that while a complete switch isn't planned, they aim to create a unified specification and architecture that could be implemented across multiple languages using AI tools. The team plans to start with a specification for SDK Rust, potentially using a hexagonal architecture approach, with the goal of delivering the first version in a couple of months after defining quality gates and conducting performance tests against existing SDKs.

### Rust Initiatives and Project Updates

Yurii discussed Rust's growing popularity and advantages over other languages, particularly highlighting its compilation time benefits. He mentioned current Rust initiatives including a Midnight deed method and verifiable credential project that will be integrated into the Identos platform. The team decided to put the Kubernetes project for Identus on hold due to capacity constraints, choosing instead to focus on delivering simpler solutions using AI agents.
