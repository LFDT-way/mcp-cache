## Details

### Project Updates and Automation Focus

The team met to discuss project updates, with Pat explaining that they are focusing on automating HypoLedger-related tasks due to increased workload. Pat confirmed that Sadie has been selected as the mentee for the mentoring program, though Pat noted that Yuri and Javi would provide more detailed updates on this program. The conversation ended with Pat preparing to share his screen for a presentation.

### Platform Release Version 2.17 Announcement

Pat announced a new platform release (version 2.17) that includes updates to Cloud Agent Mediator and SDKTS components. The release highlights include official support for Vidya and NeoVisum backend, as well as fixes for long-overdue JWT and prescriptive JWT credential format issues in SDKTS. Pat acknowledged the contributions of many new contributors to this release.

### SDK KMP Version 5.0.0 Release

Yurii announced the release of SDK KMP version 5.0.0, noting that digital key credential support is missing but will be addressed in upcoming releases using AI agents and examples from other SDKs. He also mentioned that Fábio started a PR for DIDCOM messaging support using a mediator, which Yurii is currently working on and plans to include in a release within a month. Fábio offered to clean up and add support to the mediator based on previous work he had done with Javier, which was already partially functional.

### Third-Party Dependency and Workspace Updates

Fábio discussed updating third-party dependencies on the mediator due to flagged security issues and received approval from Yurii and Pat to proceed with creating a new version. Pat then explained their internal experimentation with a workspace concept using an umbrella repository with submodules to provide a higher-level project overview and development environment. The workspace aims to simplify development by standardizing dependencies and workflows across multiple Hyperledger repositories, though it remains private for now.

### Skills Repository and AI Management

Yurii explained the purpose of a new repository, highlighting its potential for managing skills and components across platforms, particularly when using AI agents. Pat discussed the benefits of shared skills for automating workflows and knowledge transfer, providing examples from NeoPrism. They also mentioned plans to migrate the workspace to Hyperledger. The discussion then shifted to the Linux Foundation mentorship program, though details were not provided in the transcript.

### User Authentication Implementation Progress

Yurii and Pat discussed progress on creating issues and implementing a keycloak service for user authentication, which will be shared between them to ensure a consistent experience for all users. Seydi reported on a kickoff meeting with Javier where they decided to start working on the project using Express for the portal API backend, and mentioned they had opened a draft PR with plans to pair with Javier on the code structure. Yurii invited Seydi to present their progress at the next identity community call if they have items to demonstrate.

### DIF Recommendations for Prisma Application

Fábio proposed applying for the Decentralized Identity Foundation's (DIF) recommendations for DIP methods for Prisma, noting it would be a simple process taking a few months. Yurii inquired about the purpose of the process, and Fábio explained it helps analyze and recommend suitable methods, with only two currently recommended and seven to eight more in the pipeline. Fábio agreed to share the relevant links on Discord for further discussion.
