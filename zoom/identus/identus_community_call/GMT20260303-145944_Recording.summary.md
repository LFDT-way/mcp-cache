## Details

### Webcoding Agents and Tools Discussion

Yurii discussed his exploration of webcoding agents and their potential to speed up the execution of their backlog, despite occasional inefficiencies. He noted that with proper planning and step-by-step instructions, these agents could save time. Fábio shared that he uses cloud-based tools for company work due to faster processing and lack of a powerful local machine, though he does run some models locally for smaller tasks. Yurii mentioned trying to run Square locally but found it unproductive for code changes, preferring cloud-based tools like CodeSandbox for better performance.

### VDR Driver and Release Planning

The team discussed the VDR driver merge to the Cloud Agent repo and upcoming releases for Prismode and Cloud Agent, pending QI assessment and end-to-end testing. They identified the need for compatibility testing between ScalaD, Neoprism, and PRISM node driver, with Pat noting potential deviations in Neoprism's protobufs. The team also considered applying for the Linux Foundation's Centralized Trust Mentorship Program to develop model context protocol with Identus components for AI agents, but decided to put it on hold due to lack of community engagement, with Yurii requesting interested participants to contact him by March 13.

### Neoprezum Version 0.12 Updates

Pat presented updates on the new version 0.12 of Neoprezum, which includes a breaking change to restructure endpoints and introduce a more user-friendly OpenAPI UI, replacing Swagger UI. The new endpoints support submitting operations directly, including Prisma checks, and Pat explained that this change is part of their internal project integration to test NeoQ with the SDK. Yurii asked about the signing process, to which Pat clarified that SDKTS will sign the object, while NeoQ will sign the transaction. Yurii also inquired about tracking operation status and metadata, and Pat confirmed that operation IDs and transaction IDs can be used to query endpoints for detailed information, including metadata like previous hashes.

### Sign Operations and Project Updates

The team discussed accepting lists of sign operations for deterministic T, with Pat confirming they can be submitted in one go to get a single transaction. Yurii provided updates on two ongoing projects: working with the BlockFrost team to expose the presenter resolver, and contributing to open badges self-assessment, which is expected to be completed in a few months. The conversation ended with Yurii encouraging attendees to use the remaining time productively before the next meeting in two weeks.
