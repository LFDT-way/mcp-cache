## Details

### Platform Release and Mentorship Program

Yurii announced the platform release 2.17, which will include significant changes to SDKTS with a switch from a single package to a monorepo structure. He also discussed the Linux Foundation Decentralized Trust Mentorship Program, which received around 114 applications, with AI tools being used to match candidates and evaluate their contributions. Yurii mentioned that more guidance from Linux Foundation is expected this week regarding mentors and applications, with results about the process expected in the next one to two weeks.

### 8X Platform Migration Update

Javi announced that the documentation portal already reflects the migration guide from 7X to 8X, and he expects to release version 8.0 this week as part of the platform release. He encouraged the community to engage in conversations with the team before introducing new tasks or contributions, emphasizing the importance of creating meaningful PRs that represent a good investment of time and resources. Javi advised team members to first create an issue, then discuss it with the team before making contributions to avoid random changes in the codebase.

### GitHub Contributions Strategy Discussion

Javi and Yurii discussed implementing GitHub capabilities for contributing to their SDKTS repository, including setting up "good first issues" that contributors can choose from. Javi emphasized the need to focus on contributions that bring real value to the SDK rather than accepting any code changes. Yurii requested that Javi identify specific issues that could be picked up by contributors, as there was a question about this in the Discord community.

### GitHub Issue Organization Planning

Javi and Yurii discussed organizing GitHub issues by implementing labels, particularly the "good first issue" label, to make it easier for contributors to start working on the platform. Javi agreed to select 3-5 good first issues in SDKTS and work with Spot on Cloud Agent and Mediator, while also applying similar organization to SDK, KMP, and Swift repositories. Yurii also mentioned completing the unification of git attributes, editor configs, and shared CI files across all repositories, making it easier for contributors to work on documentation and configuration files.

### PR Review and Updates Meeting

Javi discussed a PR that took over a month to complete but resulted in high value due to its quality and the engagement with a new community member. Seydi mentioned having questions about some decisions made in their recent dual path PR. Yurii closed the meeting by thanking everyone and announcing the next meeting in one week.
