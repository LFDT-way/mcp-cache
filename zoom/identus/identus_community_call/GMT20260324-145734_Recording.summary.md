## Overview

The meeting focused on updates to the Identus SDK and Neo Prism component. Javi presented the pre-release candidate 8.0.0RC1, introducing a breaking change requiring migration from version 7, and announced plans to release RC2 later that day with the main version 8.0.0 expected by week's end. ## Details

### SDK Migration to Version 8

Javi presented updates on the SDK migration from version 7 to 8, introducing a breaking change with a migration guide available in the documentation portal. He announced that RC2 would be released later that afternoon, with the main version 8.0.0 expected by the end of the week. Javi also discussed plans for new Identus React components to simplify development, though these are still in early development stages and will require additional iterations before public release.

### Neo Prism Component Updates

Pat presented updates to the Neo Prism component, which now uses the mesh SDK to build and submit transactions directly using BlockFrost or submit APIs, making it lighter and reducing infrastructure requirements. Pat demonstrated a minimal version of the service running locally, showing how it can submit operations and index transactions on the chain. The new setup successfully submitted a test transaction, which was confirmed in the indexer shortly after the demonstration.

### Identus Cost-Effective Implementation Review

Javi reviewed Pat's work on allowing everyone to use Identus in a cost-effective way and suggested emphasizing this in the documentation. Pat confirmed plans to release the new version by the end of the week. Elias inquired about the connection between the SDK and the mentorship program interface, but Javi explained that the mentorship program proposal needs Linux Foundation approval before proceeding, and suggested Elias wait for Yuri's return for more details.
