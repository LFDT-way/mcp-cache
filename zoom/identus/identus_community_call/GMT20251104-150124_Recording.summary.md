The conversation ended with presentations on Swift SDK capabilities for issuing credentials and plans for TypeScript SDK improvements, including type safety enhancements and community project collaborations.

## Details

### SDK Updates and Release Planning

Javier introduced the agenda for the meeting, which included updates on the Swift SDK issuance by Gonzalo, changes from the recent 2.16 release, and plans for the upcoming 2.17 release. Gonzalo was called out on Slack to join the meeting and discuss the Swift SDK updates. Javier mentioned that the TypeScript SDK had a major breaking change from version 6 to 7, with detailed documentation available. The meeting also touched on the Kotlin SDK being on pause, and Javier invited others to discuss updates on the cloud agent or mediator, though he was less informed about these topics.

### Cloud Agent and Mediator Updates

Yurii discussed updates to Cloud Agent and Mediator, including fixes, upgrades, and bug fixes, as well as the introduction of the Neopreism component. Javier and Yurii agreed to start using Neo Prism as a standalone application and to adapt it better into the technology stack in the next milestone release. They also discussed the VDR catalyst proposal, planning to organize a session on the community call or another date. Javier outlined the scope for VCDM 2.0, including implementing the new verifiable credential data model on SDKs, ongoing TypeScript SDK improvements, and general maintenance tasks.

### PrismD Mediator Feature Discussion

The team discussed the implementation of PrismD in the mediator feature, which currently supports both peer DID and Prism DID communication. Fabio explained that the mediator's role is to resolve documents and support PrismD, while Javier raised concerns about Web3 wallets signing every message, which the team clarified is not required. The discussion highlighted that while PrismD offers updatable keys and better resolution capabilities, it may not provide significant advantages over peer DID for all use cases, leaving the choice to users when the feature is implemented in SDKs.

### DID Mediation and SDK Improvements

The team discussed the correlation of DID documents and mediator functionality, clarifying that while Prism wallets create non-correlated DIDs due to their random derivation paths, the mediator maintains a connection between the DID and the original wallet through registration. Javier presented plans to improve type safety in the TypeScript SDK by implementing both compile-time and runtime validation, and announced intentions to share community projects with Identus, including a React-based identity product and an offline-first agent.

### Swift SDK JWT Credential Updates

Gonçalo presented the Swift SDK's new capabilities for issuing JWT and SDJWT credentials, demonstrating how the SDK can generate verifiable credentials with disposable fields and validate them according to W3C specifications. The SDK supports creating credentials with various claim types, including arrays and objects, and includes built-in validations for proper formatting. The team discussed potential improvements to the DSL implementation, with Fabio suggesting the creation of a separate method without the key parameter, though Gonçalo felt it wasn't necessary due to existing validation checks.
