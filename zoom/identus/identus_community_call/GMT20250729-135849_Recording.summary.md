### Deterministic Prisma Deeds Proposal

Fábio presented a proposal for generating deterministic Prisma deeds using a master key approach, similar to Cardano's key derivation. The system would use a single create event with the master key, followed by separate update events for additional key information. Javier raised a question about the determinism of the system, which Fábio explained was achieved by using consistent labels and raw data to generate the same deeds. Gonçalo noted that this method differs from the previous approach by eliminating the need for an update operation, making the system more efficient.

### New Deed Creation Method Proposal

The team discussed a proposal for a new deed creation method that would make it easier and more efficient for users, particularly when integrating with wallets. Fabio explained that the proposal would allow users to create deeds using a private key or a mnemonic phrase, similar to how addresses are generated. Gonçalo and Yurii agreed that this new method should be used by all applications, not just Ways, and should be presented as a recommendation or extension rather than a replacement for existing deeds. Fabio also outlined two options for users with existing deeds: updating the master key and searching the blockchain for matching deeds, though he noted that this would be a less common operation.

### Derivation Key Constants Discussion

The team discussed the need for unique derivation keys in their proposal, with Fabio explaining that only two constants would be required. They clarified that while testnet and mainnet addresses differ due to additional bytes at the beginning, the private keys remain the same. Fabio suggested it might be possible to map testnet addresses to mainnet addresses at a low level, as the public keys are identical.
